# D3.js

## 前言

**定位**：Data-Driven Documents（数据驱动文档），基于 Web 标准（SVG/Canvas/HTML）的 JavaScript 可视化库，2011 年发布至今是 Web 可视化的事实标准。

**核心价值**：
- 把数据"绑定"到 DOM，数据的任何变化自动反映到图形
- 提供选择/过渡/比例尺/轴等可视化原语（primitives），不强制图表类型
- 完全控制：用 D3 画任何你能想到的可视化，从柱状图到地图到力学图
- 生态庞大：D3 是一组包（d3-selection、d3-scale 等），按需引入

**五大特性**：
1. **数据驱动**：D3 的核心理念，`data()` 把数据绑定到 DOM
2. **SVG/Canvas 都支持**：D3 v6+ 模块化，可单独用 d3-selection + d3-scale
3. **过渡与动画**：`d3.transition()` 帧动画零代码
4. **力导向布局**：`d3-force` 实现力导向图、树、弦图等
5. **比例尺系统**：`d3-scale` 把数据值映射到视觉值（位置/颜色/大小）

**对比表**：

| 维度 | D3.js | Chart.js | ECharts | Plotly | Recharts |
|---|---|---|---|---|---|
| 定位 | 底层可视化库 | 简单图表 | 国内大屏 | 交互图表 | React 图表 |
| 学习曲线 | 高 | 低 | 中 | 低 | 低 |
| 自定义能力 | ✅ 极强 | ⚠️ 中 | ✅ 强 | ⚠️ 中 | ⚠️ 中 |
| 性能 | ✅ | ✅ | ✅ | ⚠️ | ✅ |
| 3D | ⚠️ | ❌ | ✅ | ✅ | ❌ |
| 适合 | 复杂定制可视化 | 标准图表 | 大屏 | 报表 | React 项目 |

## 关键代码

### 一、安装与基础

```bash
# 完整 D3
npm install d3

# 按需引入
npm install d3-selection d3-scale d3-axis d3-shape
```

```typescript
import * as d3 from "d3";

// 1. 创建一个简单的柱状图
const data = [10, 20, 30, 40, 50];

const svg = d3.select("#chart")
  .append("svg")
    .attr("width", 400)
    .attr("height", 200);

svg.selectAll("rect")
  .data(data)
  .enter()
  .append("rect")
    .attr("x", (_, i) => i * 70)
    .attr("y", d => 200 - d * 3)
    .attr("width", 60)
    .attr("height", d => d * 3)
    .attr("fill", "steelblue");
```

### 二、数据绑定（Data Join）

```typescript
// D3 的核心模式
const data = [10, 20, 30];

const circles = d3.select("svg")
  .selectAll("circle")    // 选择现有
  .data(data);            // 绑定数据

// enter：新增的（数据比 DOM 多）
circles.enter()
  .append("circle")
    .attr("r", d => d)
    .attr("cx", (_, i) => (i + 1) * 50)
    .attr("cy", 50)
    .attr("fill", "blue");

// exit：删除的（DOM 比数据多）
circles.exit().remove();

// update：更新现有的
circles
  .attr("r", d => d)
  .attr("fill", d => d > 20 ? "red" : "blue");
```

### 三、比例尺

```typescript
import * as d3 from "d3";

const data = [10, 50, 100, 200, 500];

// 1. 线性比例尺
const linear = d3.scaleLinear()
  .domain([0, d3.max(data)!])     // 输入域
  .range([0, 500]);                // 输出范围

linear(100);  // 100
linear(250);  // 250

// 2. 颜色比例尺
const colorScale = d3.scaleOrdinal()
  .domain(["A", "B", "C", "D"])
  .range(d3.schemeCategory10);

colorScale("A");  // "#1f77b4"

// 3. 连续颜色
const heatColor = d3.scaleSequential(d3.interpolateRdYlGn)
  .domain([0, 100]);

// 4. 柱状图专用（band）
const x = d3.scaleBand()
  .domain(data.map((_, i) => i.toString()))
  .range([0, 500])
  .padding(0.1);

// 5. 时间比例尺
const time = d3.scaleTime()
  .domain([new Date(2024, 0, 1), new Date(2024, 11, 31)])
  .range([0, 1000]);
```

### 四、坐标轴

```typescript
import * as d3 from "d3";

const svg = d3.select("svg");
const margin = { top: 20, right: 30, bottom: 30, left: 40 };
const width = 500 - margin.left - margin.right;
const height = 300 - margin.top - margin.bottom;

const g = svg.append("g")
  .attr("transform", `translate(${margin.left},${margin.top})`);

const x = d3.scaleLinear()
  .domain([0, 100])
  .range([0, width]);

const y = d3.scaleLinear()
  .domain([0, 100])
  .range([height, 0]);

// 底部 X 轴
g.append("g")
  .attr("transform", `translate(0,${height})`)
  .call(d3.axisBottom(x));

// 左侧 Y 轴
g.append("g")
  .call(d3.axisLeft(y));
```

### 五、折线图 + 区域图

```typescript
import * as d3 from "d3";

const data = [
  { date: new Date(2024, 0, 1), value: 100 },
  { date: new Date(2024, 1, 1), value: 150 },
  { date: new Date(2024, 2, 1), value: 130 },
  { date: new Date(2024, 3, 1), value: 200 }
];

const x = d3.scaleTime()
  .domain(d3.extent(data, d => d.date) as [Date, Date])
  .range([0, width]);

const y = d3.scaleLinear()
  .domain([0, d3.max(data, d => d.value)!])
  .range([height, 0]);

// 折线生成器
const line = d3.line<{date: Date, value: number}>()
  .x(d => x(d.date))
  .y(d => y(d.value))
  .curve(d3.curveMonotoneX);  // 平滑曲线

svg.append("path")
  .datum(data)
  .attr("d", line)
  .attr("stroke", "steelblue")
  .attr("stroke-width", 2)
  .attr("fill", "none");

// 区域图
const area = d3.area<{date: Date, value: number}>()
  .x(d => x(d.date))
  .y0(height)
  .y1(d => y(d.value));

svg.append("path")
  .datum(data)
  .attr("d", area)
  .attr("fill", "lightblue")
  .attr("opacity", 0.6);
```

### 六、过渡动画

```typescript
// 1. 简单过渡
svg.selectAll("circle")
  .transition()
  .duration(750)
  .attr("r", d => d * 2);

// 2. 链式过渡
circles.transition()
  .duration(500)
  .attr("r", 20)
  .transition()
  .duration(500)
  .attr("r", 10);

// 3. 缓动
circles.transition()
  .ease(d3.easeBounce)
  .duration(1000)
  .attr("cx", 300);

// 4. 数据更新动画
function update(newData: number[]) {
  const bars = svg.selectAll("rect").data(newData);

  bars.transition()
    .duration(750)
    .attr("height", d => d)
    .attr("y", d => 200 - d);

  bars.enter()
    .append("rect")
      .attr("y", 200)
      .attr("height", 0)
      .attr("fill", "steelblue")
    .merge(bars as any)
    .transition()
    .duration(750)
      .attr("y", d => 200 - d)
      .attr("height", d => d);

  bars.exit().transition()
    .attr("height", 0)
    .attr("y", 200)
    .remove();
}
```

### 七、力导向图

```typescript
import * as d3 from "d3";

const nodes = [{id: 1, name: "A"}, {id: 2, name: "B"}, {id: 3, name: "C"}];
const links = [
  {source: 0, target: 1},
  {source: 1, target: 2},
  {source: 2, target: 0}
];

const simulation = d3.forceSimulation(nodes as any)
  .force("link", d3.forceLink(links).id(d => d.id))
  .force("charge", d3.forceManyBody().strength(-300))
  .force("center", d3.forceCenter(width / 2, height / 2));

const link = svg.append("g")
  .selectAll("line")
  .data(links)
  .enter()
  .append("line")
    .attr("stroke", "#999");

const node = svg.append("g")
  .selectAll("circle")
  .data(nodes)
  .enter()
  .append("circle")
    .attr("r", 10)
    .attr("fill", "#69b3a2")
    .call(d3.drag()
      .on("start", (event, d: any) => {
        if (!event.active) simulation.alphaTarget(0.3).restart();
        d.fx = d.x;
        d.fy = d.y;
      })
      .on("drag", (event, d: any) => {
        d.fx = event.x;
        d.fy = event.y;
      })
      .on("end", (event, d: any) => {
        if (!event.active) simulation.alphaTarget(0);
        d.fx = null;
        d.fy = null;
      }));

simulation.on("tick", () => {
  link
    .attr("x1", d => (d.source as any).x)
    .attr("y1", d => (d.source as any).y)
    .attr("x2", d => (d.target as any).x)
    .attr("y2", d => (d.target as any).y);

  node
    .attr("cx", d => d.x!)
    .attr("cy", d => d.y!);
});
```

## 核心洞察

- **D3 的本质是"数据驱动 DOM"**：核心抽象是 Selection（DOM 选择集）+ Data Join（数据绑定），其他都是工具
- **D3 不强制图表类型**：Chart.js 给现成图表、D3 给原语——前者学习曲线低、后者自由度大
- **D3 v6 改用 ES Module**：原来 `d3` 整体导入（500KB+）现在按需 `d3-selection`、`d3-scale`，bundle 可降到 30KB
- **Data Join 是 D3 的灵魂**：`enter()`/`exit()`/`update()` 三段式，让数据变化映射到 DOM 增删改
- **比例尺是"数据 → 视觉"的核心**：`scaleLinear`、`scaleTime`、`scaleOrdinal` 把业务数据映射到像素坐标
- **`d3-shape` 的曲线工厂**：`line/area/arc` 是生成器，定义"如何画"，不是"画什么"
- **D3 动画用 transition**：`duration + ease` 两参数足以实现复杂动画，比 CSS 动画更灵活（可中断）
- **力导向图是 D3 的特色**：`d3-force` 实现社交网络/关系图/树布局，是其他库少有的能力
- **D3 的学习曲线陡但天花板高**：从 Chart.js 入手、从 D3 进阶，是前端可视化的标准路径
- **D3 v7 引入 `d3.group/d3.rollup`**：替代 `lodash.groupBy` 的现代 API，与 JavaScript 标准对齐
- **D3 的 SVG 限制**：1 万 + 元素性能下降，要用 Canvas（d3 + canvas 库如 Konva）
- **Observable 是 D3 团队的新产品**：基于 Notebook 的数据可视化协作平台，是 D3 未来的"御用工具"

## 跨项目引用

- **[[svg]]**：D3 默认基于 SVG 渲染，矢量图无损缩放
- **[[canvas]]**：D3 + Canvas（d3 + Konva/PixiJS）处理大数据可视化
- **[[react]]**：`react-d3` / `recharts` / `nivo` 是 D3 思想的 React 包装
- **[[vue]]**：D3 同样适用，用 `ref` 引用 SVG 元素
- **[[typescript]]**：D3 v6+ 完整 TS 支持，泛型让 Selection 类型安全
- **[[observable plot]]**：D3 团队推出的高层 API，类似 Vega-Lite
- **[[chart.js]]**：简单图表的首选，D3 用于复杂定制
- **[[plotly]]**：Plotly 是 Plotly.js + D3 的结合，交互更强
- **[[echarts]]**：国内大屏首选，D3 用于科研/定制
- **[[python]]**：D3 的 Python 复刻是 `bokeh`、`plotly` 的 Python 版
- **[[d3-force]]**：力导向算法被 NetworkX、Neo4j 借鉴
- **[[observable]]**：D3 团队创始人 Mike Bostock 创立的 Notebook 平台
