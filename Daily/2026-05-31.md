**技术选型**: TypeScript + esbuild → CommonJS bundle

**实现功能**:

- ✅ `Ctrl+Shift+D` — 总结选中内容

- ✅ `Ctrl+Shift+M` — 笔记转思维导图
- ✅ `Ctrl+P → Wiki: 自动分类整理` — AI 扫描全部词条自动归类
- ✅ `Ctrl+P → Wiki: 生成索引` — 自动生成 `_index.md`
- ✅ 侧边栏 ✨ 按钮快速唤起
- ✅ 自动保存到 vault（`app.vault.create()`）

**DeepSeek API 配置**:

- Max tokens: 4000
- Temperature: 0.7

### 3. LLM Wiki 系统

**目录结构**:
```
Wiki/
├── _index.md               ← 自动生成的知识库索引
├── _templates/
│   ├── wiki-entry.md        ← 词条模板
│   └── wiki-category.md     ← 分类模板
└── [分类目录]/              ← AI 自动创建
    └── [词条].md
```

**Wiki 模板设计**:
```yaml
---
tags: [wiki, category]
type: wiki-entry
created: "date"
aliases: []
related: []
category: ""
---
# 主题名
## 概述 → 核心概念 → 详细说明 → 相关条目 → 参考资料
```

**工作流程**:
1. 用户按 `Ctrl+Shift+W` → 输入词条名
2. DeepSeek 生成结构化百科内容
3. 自动添加 frontmatter 元数据
4. 保存到 `Wiki/[分类]/[词条].md`
5. 用户按 `Ctrl+Shift+L` → AI 分析笔记找到关联词条
6. 用户按 `Ctrl+P → Wiki: 自动分类整理` → AI 批量整理

## 🔧 解决的技术问题

### 问题 1: GitHub 被墙 → 插件下载失败
- **方案**: 使用 jsDelivr CDN (`cdn.jsdelivr.net/gh/...`) 绕过
- **影响**: `obsidian-enhancing-mindmap` 成功下载

### 问题 2: PowerShell 字符串转义
- **方案**: 使用 `curl` 命令替代 PowerShell `Invoke-WebRequest`

### 问题 3: Obsidian 插件 CommonJS 导出格式
- **方案**: 使用 esbuild `--format=cjs` + `__toCommonJS` 包装

### 问题 4: obsidian-mcp-server 连接超时
- **原因**: Obsidian 启动后 REST API 需初始化时间
- **解决**: 增加等待时间，obsidian-brain 作为备用
