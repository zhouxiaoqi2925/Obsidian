## 2. 硬性规则 (防 AI 造假)

### 2.1 录制时长
- **最低时长：120 秒** (硬性要求)
- **录制脚本**：系统随机生成 5 段文字，每段 8 字
  - 包含中文、英文、数字、特殊字符 (如：`【】`、表情符号读法)
  - 5 段内容组合随机，30 秒内必须逐字朗读完整
  - 朗读时头部需要做 8 个方向运动 (上/下/左/右/左上/右上/左下/右下)

### 2.2 录制参数
- 分辨率：≥ 720p (1280x720)
- 帧率：≥ 25fps
- 码率：≥ 2Mbps
- 音频：44.1kHz / 16bit / 立体声
- 时长：120s ≤ t ≤ 300s

### 2.3 环境要求
- 光线均匀 (无强光直射/逆光)
- 无背景音乐
- 无回声 (房间隔音检测)
- 人脸占比 ≥ 30% 画面
- 单人录制 (无他人入镜)

## 3. 7 项防伪检测

### 3.1 眨眼频率分析
- 真人正常眨眼：15-20 次/分钟
- AI 生成视频：< 5 次/分钟 或 > 30 次/分钟
- **算法**：MediaPipe Face Mesh + EAR (Eye Aspect Ratio) 时序分析

### 3.2 微表情识别
- 嘴角、眉毛、额头的细微运动
- 真人在朗读时有自然微表情 (0.5-2s 持续)
- **算法**：Py-Feat / OpenFace 2.0

### 3.3 唇形与音频对齐
- 音素级时间戳对齐检测
- 偏差 > 100ms 视为异常
- **算法**：Wav2Vec2 + 音素识别

### 3.4 反射光分析
- 皮肤表面的高光区域分布
- 真人有非均匀反射 (油性/干性差异)
- AI 生成通常全局均匀
- **算法**：Specular Highlight Detection

### 3.5 头部运动连续性
- 头部 6DoF 轨迹平滑度
- 真人有微抖动 (生理性震颤)
- AI 生成轨迹过于平滑
- **算法**：惯性传感器融合 (可选) + 视频特征点追踪

### 3.6 深度图一致性
- 3D 面部结构合理性
- 真人有正常深度梯度
- AI 生成可能有穿模/异常凹陷
- **算法**：MiDaS / ZoeDepth 单目深度估计

### 3.7 活体检测 (新加)
- 随机动作响应 (点头/张嘴/眨眼)
- 5 秒内完成 3 个动作
- **算法**：动作识别模型 (3D-CNN + LSTM)

## 4. 数据模型

```sql
-- 肖像确权主表
CREATE TABLE portrait_verifications (
    id BIGSERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL,
    real_name VARCHAR(50) NOT NULL,    -- 实名
    id_card_hash VARCHAR(64) NOT NULL,  -- 身份证 SHA-256
    video_url TEXT NOT NULL,            -- MinIO 加密存储路径
    video_hash VARCHAR(64) NOT NULL,     -- 视频 SHA-256 防篡改
    encryption_key_id VARCHAR(50),       -- KMS 密钥 ID
    duration_seconds INTEGER NOT NULL,
    resolution VARCHAR(20),
    
    -- 防伪检测结果
    blink_score DECIMAL(3,2),           -- 0-1
    micro_expression_score DECIMAL(3,2),
    lip_sync_score DECIMAL(3,2),
    reflection_score DECIMAL(3,2),
    motion_continuity_score DECIMAL(3,2),
    depth_consistency_score DECIMAL(3,2),
    liveness_score DECIMAL(3,2),
    overall_score DECIMAL(3,2),         -- 加权综合分
    
    -- 状态
    status VARCHAR(20) DEFAULT 'pending',  -- pending/passing/failed/reviewing
    failure_reasons JSONB,
    
    -- 审核
    auto_approved_at TIMESTAMP,
    manual_reviewer_id INTEGER,
    manual_review_at TIMESTAMP,
    manual_review_notes TEXT,
    
    -- 授权书
    authorization_doc_url TEXT,
    signed_at TIMESTAMP,
    
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 审计日志 (3 年保留)
CREATE TABLE portrait_audit_logs (
    id BIGSERIAL PRIMARY KEY,
    verification_id BIGINT,
    action VARCHAR(50) NOT NULL,        -- view/edit/approve/reject/delete/export
    operator_id INTEGER NOT NULL,
    operator_ip INET,
    operator_device TEXT,
    details JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_pv_user ON portrait_verifications(user_id);
CREATE INDEX idx_pv_status ON portrait_verifications(status);
CREATE INDEX idx_audit_verification ON portrait_audit_logs(verification_id);
CREATE INDEX idx_audit_created ON portrait_audit_logs(created_at);
```

## 5. 技术架构

### 5.1 录制 SDK (Web)
- 浏览器原生 `MediaRecorder` API
- WebAssembly + TensorFlow.js 实时预览
- 录制前环境检测 (摄像头/麦克风权限、网络延迟)
- 实时质量监控 (丢帧/码率/光线)

### 5.2 AI 检测服务 (Python)
- 7 个独立微服务 (FastAPI)
- 模型：MediaPipe + Py-Feat + Wav2Vec2 + MiDaS
- GPU 推理：NVIDIA T4 / A10
- 单次检测 ≤ 60s (120s 视频)

### 5.3 存储
- MinIO 加密桶 (AES-256 server-side)
- KMS 密钥管理 (腾讯云/阿里云 KMS)
- 冷数据归档：对象存储 (低频访问层)
- 哈希上链 (可选) - 长安链 / FISCO BCOS

### 5.4 审核工作流
- AI 初审 (通过率 70%) → 人工抽检 (30%)
- 高风险 (分数 0.5-0.7) → 必人工审
- 低风险 (>0.9) → 自动通过
- 异常 (<0.5) → 自动拒绝 + 申诉入口

## 7. 合规要点

- **《个人信息保护法》PIPL**：单独同意 + 最小化原则
- **《数据安全法》DSL**：数据分类分级 + 加密存储
- **《生成式人工智能服务管理暂行办法》**：深度合成备案
- **网信办深度合成备案材料包**：
  - 算法备案号
  - 训练数据来源证明
  - 安全评估报告
  - 用户协议 + 隐私政策
  - 肖像确权流程文档
  - 应急处置预案
