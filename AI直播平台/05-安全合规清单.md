## 1. 数据安全

### 1.1 传输加密
| 场景 | 措施 | 标准 |
|---|---|---|
| 用户端 ↔ 服务器 | TLS 1.3 | 强制 HTTPS |
| 服务器 ↔ 服务器 | mTLS (双向认证) | 内部 K8s service mesh |
| 服务器 ↔ 数据库 | SSL 连接 | PostgreSQL `sslmode=require` |
| 服务器 ↔ 对象存储 | HTTPS + 签名 URL | MinIO/COS/OBS |
| API 调用 | HMAC-SHA256 签名 | 时间戳防重放 (±300s) |

### 1.2 存储加密
| 数据类型 | 加密方式 | 密钥管理 |
|---|---|---|
| 肖像确权视频 | AES-256-GCM | 腾讯云 KMS / 阿里云 KMS |
| 训练视频 | AES-256-GCM | 同上 |
| 数字人模型 | AES-256-CBC | 同上 |
| 身份证号 | SM4 国密 + SHA-256 哈希 | 单独密钥 (年度轮换) |
| 手机号 | 中间 4 位脱敏 + 加密索引 | 同上 |
| 银行卡 | 全文加密 + 不存储 CVV | PCI DSS |
| 密码 | bcrypt (cost=12) | 单向哈希 |
| 私钥 | HSM 加密机 | 物理隔离 |

### 1.3 密钥生命周期
- **生成**：HSM 真随机
- **存储**：KMS 集中管理，永不明文落盘
- **轮换**：自动 90 天 (主密钥) / 30 天 (数据密钥)
- **吊销**：即时生效 + 触发数据重加密
- **审计**：所有密钥使用记录留痕

## 2. 租户隔离

### 2.1 数据库隔离
```sql
-- 方案: Schema 级隔离 (推荐)
CREATE SCHEMA tenant_acme;
CREATE SCHEMA tenant_globex;

-- 应用层通过 RLS (Row Level Security) 强制
ALTER TABLE users ENABLE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON users
    USING (tenant_id = current_setting('app.tenant_id')::INTEGER);
```

### 2.2 资源隔离
| 资源 | 隔离策略 |
|---|---|
| CPU | K8s LimitRange + ResourceQuota |
| 内存 | 同上 |
| GPU | 命名空间独占 + 队列调度 |
| 存储 | 独立 PVC + 配额 |
| 网络 | NetworkPolicy (default-deny) |
| 缓存 | Redis Key 前缀 `tenant:{id}:` |

### 2.3 故障隔离
- **熔断**：Hystrix / Sentinel (按服务/方法)
- **降级**：核心 API 自动降级 (限流/排队)
- **超时**：3s 读 / 10s 写 (可配置)
- **重试**：指数退避，最大 3 次

## 3. 鉴权与授权

### 3.1 鉴权流程
```
用户登录
  ↓
密码 + 短信/邮箱验证码
  ↓
颁发 JWT (Access Token 15min + Refresh Token 30d)
  ↓
Refresh Token 滚动续期
  ↓
登出 → 吊销 Refresh (黑名单)
```

### 3.2 多因子认证 (MFA)
| 角色 | 必开 MFA | 方式 |
|---|---|---|
| 超级管理员 | ✅ | TOTP (Google Authenticator) + 短信 |
| 运营总监 | ✅ | TOTP |
| 审核员 | ✅ | TOTP |
| 财务 | ✅ | TOTP + U盾 (大额操作) |
| 普通用户 | ❌ (可选) | 短信 / 邮箱 |
| 直播主播 | ✅ (开播时) | 人脸识别 (活体) |

### 3.3 细粒度授权 (RBAC + ABAC)
- **角色**：超管/运营/审核/客服/财务/主播/用户
- **属性**：租户/部门/地域/设备/IP
- **策略**：Casbin / OPA (Open Policy Agent)
- **审计**：所有授权决策留痕

## 4. 审计与监控

### 4.1 审计日志 (3 年保留)
| 类型 | 字段 | 保留期 |
|---|---|---|
| 登录日志 | 用户/时间/IP/设备/结果 | 1 年 |
| 操作日志 | 操作者/对象/前后值/IP | 3 年 |
| 支付日志 | 订单/金额/渠道/状态 | 5 年 (财务合规) |
| 肖像审核 | 审核员/结果/原因/时间 | 3 年 |
| 数据导出 | 导出人/范围/时间/水印 | 3 年 |
| 系统配置变更 | 修改人/前后值/时间 | 3 年 |

### 4.2 监控告警
- **指标**：Prometheus + Grafana
- **日志**：Loki + ES (双写)
- **链路**：Jaeger / SkyWalking
- **告警**：AlertManager (钉钉/飞书/企微)

### 4.3 关键告警
| 告警 | 阈值 | 级别 |
|---|---|---|
| 登录失败突增 | > 100/min/账号 | P1 |
| 大额退款 | > 5000 元 | P1 |
| 数据导出异常 | > 1 万条 | P1 |
| GPU 持续高负载 | > 95% (10min) | P2 |
| 接口错误率 | > 1% (5min) | P2 |
| 敏感词命中 | 单条 | P0 (实时) |

## 5. 反作弊与防倒卖

### 5.1 设备指纹
- 浏览器：Canvas + WebGL + Audio + 字体指纹
- 移动端：IMEI + MAC + Android ID + IDFA
- 桌面端：MAC + 硬盘序列号 + CPU ID
- 相似度匹配：同一用户最多 3 台设备

### 5.2 调用频率限制
| 接口 | 限制 |
|---|---|
| 登录 | 5 次/min/IP, 10 次/hour/账号 |
| 短信 | 1 次/60s/手机, 5 次/day/手机 |
| TTS 合成 | 100 次/min/形象 |
| 数字人推流 | 20 路同时/账号 |
| API 调用 | 1000 次/hour/形象 |
| 数据导出 | 10 次/day/管理员 |

### 5.3 水印系统
- **静态水印**：用户 ID + 时间戳 (固定位置)
- **动态水印**：随机位置 + 半透明 (抗裁剪)
- **不可见水印**：频域水印 (抗压缩/转码)
- **直播水印**：每 5s 嵌入一次 (实时)
- **回放水印**：全程嵌入 (可追溯)

### 5.4 反爬虫
- Cloudflare 接入
- 验证码 (hCaptcha / 极验)
- 行为分析 (鼠标轨迹/停留时间)
- IP 黑名单 (实时更新)

## 8. 渗透测试与漏洞管理

### 8.1 渗透测试频率
- **季度**：第三方白盒渗透
- **月度**：自动化漏洞扫描 (Burp/ZAP/ nuclei)
- **每周**：依赖组件漏洞扫描 (Snyk/Trivy)
- **每日**：Web 资产巡检

### 8.2 漏洞响应 SLA
| 等级 | 描述 | 响应时间 | 修复时间 |
|---|---|---|---|
| P0 紧急 | RCE/数据泄露 | 1h | 24h |
| P1 高危 | SQLi/XSS/越权 | 4h | 7d |
| P2 中危 | CSRF/信息泄露 | 24h | 30d |
| P3 低危 | 理论风险 | 7d | 90d |

### 8.3 漏洞奖励计划
- 平台：漏洞盒子 / HackerOne
- 奖励：P0 5万 / P1 1万 / P2 5千 / P3 1千
- 范围：生产环境 + 公开测试环境

### 9.1 备份策略
| 数据 | 备份频率 | 保留期 | 异地 |
|---|---|---|---|
| 数据库 | 全量 1d + 增量 1h | 30d | ✅ 跨区域 |
| 对象存储 | 1d | 90d | ✅ 跨区域 |
| 配置文件 | 1d | 365d | ✅ |
| 审计日志 | 1h | 3y | ✅ |
| 密钥 | 即时 | 永久 | ✅ 多地 |

### 9.2 灾难恢复
- **RTO**（恢复时间目标）：≤ 30min
- **RPO**（恢复点目标）：≤ 5min
- **演练**：每季度一次 (主备切换 + 数据恢复)
- **多活**：跨区域双活 (主+备)
