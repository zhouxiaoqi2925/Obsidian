# 直播SaaS中控台 · 设计文档

## 1. 平台支持矩阵

| 平台 | 接入方式 | 直播能力 | 备注 |
|---|---|---|---|
| 抖音 | 开放平台 OAuth 2.0 | 推流/弹幕/商品/数据 | 主战场 |
| 快手 | 开放平台 OAuth 2.0 | 推流/弹幕/商品/数据 | 主战场 |
| 小红书 | 企业号 + 蒲公英 | 推流/弹幕/商品 (受限) | 需企业资质 |

| TikTok Shop | 国际版开放平台 | 推流/弹幕/商品/全球数据 | 跨境 |

### 3.2 快手/小红书/视频号/TikTok
结构类似，差异点：
- **快手**：推流地址格式 `rtmp://push-kuaishou-live/...`
- **小红书**：需企业认证 + 单独申请直播能力
- **视频号**：微信开放平台 + `wx-open-live` SDK
- **TikTok**：国际版 (需海外服务器) + 不同 API 端点

## 4. 直播引擎

### 4.1 数字人驱动
- **音频流**：CosyVoice TTS 流式输出
- **视频流**：SadTalker / LivePortrait 唇形同步
- **编码**：FFmpeg 实时合成 (RTMP 推流)
- **延迟**：< 1s (端到端)
- **质量**：1080p / 30fps / 4Mbps

### 4.2 多直播并发
- 单服务器支持 20 路同时直播
- GPU 池：4 张 A10 (24GB)
- 队列调度：公平调度 (FIFO) + VIP 优先
- 资源监控：CPU/GPU/带宽/磁盘

### 4.3 推流协议
- 主推流：RTMP (兼容所有平台)
- 备份：SRT (低延迟/抗丢包)
- 测试：HLS (Web 预览)
- 录制：本地 MP4 + 平台云端双备份

## 5. 弹幕 AI 互动

### 5.1 弹幕采集
- 每 2s 拉取增量弹幕
- 优先级：付费礼物弹幕 > 关注用户 > 普通用户
- 去重：同用户 5s 内同内容合并
- 过滤：关键词黑名单 + 表情符号 + 营销链接

### 5.2 意图识别
模型：BERT-base (中文) + 7 类意图
- 问候 (你好/在吗/hi)
- 商品咨询 (多少钱/有货吗/尺码)
- 购买意向 (怎么买/下单/链接)
- 砍价 (便宜点/优惠/折扣)
- 投诉 (问题/差评/不满意)
- 闲聊 (今天/天气/吃饭)
- 无意义 (666/表情/单字)

### 5.3 智能回复
- 知识库匹配 (商品库 + 常见问题)
- LLM 兜底 (DeepSeek-V3 / GPT-4o)
- 话术模板 (50+ 模板)
- 风险控制：涉政/涉黄/竞品拦截

### 5.4 频率控制
- 单直播每 5s 最多 1 条 AI 弹幕
- 同内容 30s 内不重复
- 高峰期 (弹幕 > 100/min) 智能抽样回复

## 6. 商品讲解

### 6.1 商品库
- 与后台商品系统打通 (ERP/WMS)
- 字段：商品ID/名称/价格/规格/卖点/优惠/库存
- 导入方式：批量上传 (Excel) / API 同步 / 手工录入

### 6.2 自动讲解
- 5 段循环话术 (开场/卖点/优惠/催单/收尾)
- 触发时机：
  - 定时 (每 5 分钟 1 次)
  - 商品上架 (新商品首次讲解)
  - 用户询问 ("介绍一下")
  - 价格变动
- 数字人动作配合 (展示商品/指着商品)

### 6.3 弹幕点播
- 用户弹幕输入 "介绍 XX 商品" → 切换讲解
- 关键词匹配 + 模糊搜索

## 7. 紧急接管

### 7.1 触发条件
- AI 异常 (TTS 失败/数字人卡顿)
- 风险弹幕 (负面舆情)
- 用户请求 ("人工"/"真人"/"客服")
- 监管要求 (违规警告)

### 7.2 接管流程
- 通知主播 (App 推送 + 短信)
- 5s 内未响应 → 切换到预设话术
- 主播接入 → WebRTC 实时音视频
- 数字人降级为背景 + 主播画中画

## 8. 数据看板

### 8.1 实时数据 (WebSocket 推送)
- 观看人数 (UV/PV)
- 互动数据 (弹幕/点赞/分享/关注)
- 交易数据 (GMV/订单数/转化率)
- 流量来源 (推荐/关注/搜索)
- 商品排行 (Top 10)

### 8.2 离线数据 (T+1)
- 直播复盘报告
- 数字人效果评分
- 用户画像分析
- 竞品对比

## 9. 关键表设计

```sql
-- 直播任务
CREATE TABLE live_streams (
    id BIGSERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL,
    digital_human_id BIGINT NOT NULL,
    platform VARCHAR(20) NOT NULL,         -- douyin/kuaishou/xiaohongshu/wechat/tiktok
    platform_room_id VARCHAR(100),         -- 平台返回的房间 ID
    title VARCHAR(200),
    cover_url TEXT,
    scheduled_at TIMESTAMP,
    started_at TIMESTAMP,
    ended_at TIMESTAMP,
    duration_seconds INTEGER,
    status VARCHAR(20),                    -- scheduled/live/paused/ended
    push_url TEXT,                          -- RTMP 推流地址
    pull_url TEXT,                          -- 拉流地址 (HLS)
    recording_url TEXT,                     -- 录像
    
    -- 统计
    peak_viewers INTEGER DEFAULT 0,
    total_viewers INTEGER DEFAULT 0,
    gmv DECIMAL(12,2) DEFAULT 0,
    order_count INTEGER DEFAULT 0,
    conversion_rate DECIMAL(5,4),
    
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 弹幕记录
CREATE TABLE live_danmaku (
    id BIGSERIAL PRIMARY KEY,
    live_stream_id BIGINT NOT NULL,
    platform_user_id VARCHAR(100),
    platform_user_name VARCHAR(100),
    content TEXT NOT NULL,
    intent VARCHAR(20),                    -- 识别的意图
    ai_replied BOOLEAN DEFAULT false,
    ai_reply_content TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_danmaku_live ON live_danmaku(live_stream_id);
CREATE INDEX idx_danmaku_intent ON live_danmaku(intent);
```
