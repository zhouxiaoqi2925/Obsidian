## 🎬 场景 1: TikTok Shop 跨境电商（运营侧）

### 1.1 抖音电商的 8 大可借鉴打法

#### ① 内容场 + 货架场双轮驱动

抖音不是纯内容场，2023 年后大力做货架场（商城 + 搜索）。你做 TikTok Shop 也必须双场：

```
┌──────────────────────────────────────────────┐
│  内容场 (短视频 + 直播带货)                     │
│  • 短视频挂车                                  │
│  • 达人合作分销 (Affiliate)                    │
│  • 品牌自播                                    │
│  • Shop Mall 品牌馆                            │
└──────────────────────────────────────────────┘
                  ↕ 互导
┌──────────────────────────────────────────────┐
│  货架场 (商城 + 搜索 + 店铺)                    │
│  • 商城首页 (类目 + 推荐)                      │
│  • 商品搜索 (Elasticsearch + 个性化)           │
│  • 店铺主页                                    │
│  • 购物车 + 收藏                               │
└──────────────────────────────────────────────┘
```

**你的行动**: TikTok Shop 上架后，**双场都铺**，不要只押直播。短视频挂车 + 商城搜索优化两条腿走路。

#### ② 全托管 / 半托管 / 自营三种模式

抖音电商创新模式（特别是跨境）：

| 模式 | 谁负责物流 | 谁负责运营 | 适合 |
|------|----------|----------|------|
| **全托管** | 平台 | 商家供货 | 中小卖家、铺货 |
| **半托管** | 商家 | 商家自主定价 + 平台辅助 | 有供应链能力的卖家 |
| **自营** | 商家 | 商家全权 | 品牌方、大卖家 |

**你的行动**: 起步**全托管**，降低门槛；规模化后转**半托管**，拿定价权。

#### ③ 飞轮中间平台（Fwheel）

抖音电商的"飞轮"是后台中台，把商家、达人、机构、平台四方的能力抽象成可复用服务：
- 商家工作台（商品管理、订单、营销）
- 达人广场（接单、合作、数据）
- 机构后台（达人管理）
- 数据参谋 Compass

**你的行动**: 直接用 TikTok Seller Center (`seller-th.tiktok.com` 等) + Compass，**不要自建后台**，先跑通业务。

#### ④ Affiliate 分销体系

TikTok Shop 的 Affiliate 是核心流量来源。商家设置佣金，达人主动推广：
- **Open Plan**: 商品自动加入，达人可申请
- **Target Plan**: 商家定向邀请达人
- **Campaign Plan**: 短期营销活动

**你的行动**:
- 新品上市: 设 **20%+ 佣金** 引流
- 头部达人: 给独家 + 高佣
- 中腰部达人: 走 Open Plan 广撒网

#### ⑤ 数据驱动选品

抖音电商的核心是**数据选品**：
- 抖音商品榜 (`compass.tiktok.com`)
- 蝉妈妈、FastMoss、TikStar 等第三方数据工具
- 站内热搜词 + 竞品监控

**你的行动**:
- 每日看**品类飙升榜**
- 每周复盘**转化率**（曝光→点击→加购→下单→支付）
- 关注 **CTR > 3%, CVR > 1.5%, GMV/UV > 5** 的品

#### ⑥ 内容能力

抖音带货短视频的"黄金 3 秒"原则：
- 前 3 秒必须有冲突/惊喜/痛点
- 中段展示产品核心卖点（最多 3 个）
- 后段给强 CTA（"点击购物车"）

**你的行动**:
- 视频前 3 秒决定 70% 完播率
- 产品展示不超过总时长 30%
- 必须有字幕 + BGM 卡点 + 价格锚点

#### ⑦ 风控 + 合规

抖音电商风控的核心：
- 商品合规（禁售、限售品类）
- 价格管控（不能比外部贵太多）
- 内容合规（不能虚假宣传）
- 物流时效（48h 发货、7 天妥投）

**你的行动**:
- 严格审核商品资质（特别是欧美市场）
- 用 TikTok 官方的合规工具 + 第三方合规扫描
- 库存实时同步（防超卖）

#### ⑧ 数据看板

**Compass 数据参谋** 提供：
- 店铺维度: GMV、订单、流量、转化
- 商品维度: 曝光、点击、加购、下单
- 直播维度: 实时在线、互动率、转化率
- 达人维度: 带货能力、粉丝画像

**你的行动**: 每天早 9 点 + 晚 9 点看数据看板，**对关键指标设阈值告警**。

### 2.2 推荐系统（你的核心壁垒）

**从抖音学到的 5 条铁律**:

1. **多目标融合**: 不只追 CTR，还要追完播率 + 互动率 + GMV
2. **实时训练**: Monolith 秒级生效，热点视频 1 小时内推到位
3. **冷启动**: 新直播间前 20 分钟用探索流量，不能只推老主播
4. **A/B 测试**: 任何模型改动先 1% 流量灰度
5. **特征为王**: 80% 收益来自特征工程，不是模型架构

**你的技术选型**:

```yaml
Phase 1 (MVP):
  推荐: XGBoost + Faiss
  特征: Redis 在线 + 离线 T+1
  A/B: 自研简单分桶

Phase 2 (增长):
  推荐: DNN (MMoE) + 向量召回
  特征: Flink 实时
  A/B: 自研分层实验框架

Phase 3 (规模化):
```

## 💡 关键洞察（来自 6 章拆解的精华）

### 抖音成功的 5 个底层逻辑

1. **数据闭环飞轮**: 内容→消费→数据→算法→更精准内容（这是字节的真正护城河）
2. **工程基建护城河**: 不是算法，是工程规模（5000+ 服务、2500+ CDN 节点、毫秒级实时训练）
3. **多目标平衡**: 不让单一指标绑架系统（时长 + 互动 + 电商 + 创作者多方共赢）
4. **全栈自研**: 从芯片到推荐算法，从 CDN 到 RTC，几乎全自研（降低成本 + 提升效率）
5. **组织能力**: 字节"始终创业"文化 + OKR + 数据驱动决策

### 你能从中学到的 5 个非技术能力

1. **先 MVP 后迭代**: 不要追求完美，1 周内上线最小可用版本
2. **数据驱动决策**: 任何改动前看数据，不拍脑袋
3. **用户视角**: 所有功能问"用户为什么用"
4. **长期主义**: 抖音 9 年才盈利，不要急
5. **Build + Buy 平衡**: 该自研自研，该买就买（SaaS）

### 你需要警惕的 5 个坑

1. **不要重造轮子**: 音视频、CDN、数据库该买 SaaS 买 SaaS
2. **不要过早优化**: 用户量没到 10w 之前不要谈分布式
3. **不要追技术热点**: 抖音也是 90% 成熟技术 + 10% 创新
4. **不要忽视内容**: 你的核心是内容运营，技术只是工具
5. **不要忽视合规**: 跨境电商合规风险极高，出问题就是关店
