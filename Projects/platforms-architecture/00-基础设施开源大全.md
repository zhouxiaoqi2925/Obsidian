## 二、HTTP 框架 (CloudWeGo Hertz)

### 2.1 Hertz 简介

Hertz 是字节跳动开源的高性能 Go HTTP 框架:
- **QPS**: 单机 50K+ (vs Gin 25K)
- **延迟**: P99 < 10ms
- **基于**: Netpoll (字节自研 epoll 框架)
- **路由**: 静态路由 + Radix Tree

### 2.2 Coze 中的 Hertz 工具

文件路径: `backend/pkg/hertzutil/` (封装层)

```go
// pkg/hertzutil/middleware.go
package hertzutil

import (
    "github.com/cloudwego/hertz/pkg/app"
    "github.com/cloudwego/hertz/pkg/app/server"
)

// 通用中间件
func TracingMiddleware() app.HandlerFunc {
    return func(c context.Context, ctx *app.RequestContext) {
        traceID := ctx.GetHeader("X-Trace-Id")
        if traceID == "" {
            traceID = uuid.New().String()
            ctx.SetHeader("X-Trace-Id", traceID)
        }
        ctx.Set("trace_id", traceID)
        ctx.Next(c)
    }
}

// Recover 中间件
func RecoverMiddleware() app.HandlerFunc {
    return func(c context.Context, ctx *app.RequestContext) {
        defer func() {
            if r := recover(); r != nil {
                stack := debug.Stack()
                logs.Errorf("panic: %v\n%s", r, stack)
                ctx.JSON(500, map[string]any{
                    "code": errno.ErrInternal.Code,
                    "msg":  "internal error",
                })
            }
        }()
        ctx.Next(c)
    }
}

// CORS 中间件
func CorsMiddleware() app.HandlerFunc {
    return func(c context.Context, ctx *app.RequestContext) {
        ctx.SetHeader("Access-Control-Allow-Origin", "*")
        ctx.SetHeader("Access-Control-Allow-Methods", "GET,POST,PUT,DELETE")
        ctx.SetHeader("Access-Control-Allow-Headers", "Content-Type,Authorization")
        if string(ctx.Method()) == "OPTIONS" {
            ctx.AbortWithStatus(204)
            return
        }
        ctx.Next(c)
    }
}
```

## 三、ORM (GORM v2 + MySQL)

### 3.1 Coze 中的 MySQL 连接池

文件路径: `backend/infra/orm/impl/mysql/mysql.go:1-52`

```go
package mysql

import (
    "fmt"
    "os"
    "time"
    "gorm.io/driver/mysql"
    "gorm.io/gorm"
    "github.com/coze-dev/coze-studio/backend/pkg/envkey"
    "github.com/coze-dev/coze-studio/backend/pkg/logs"
)

func New() (*gorm.DB, error) {
    dsn := os.Getenv("MYSQL_DSN")
    db, err := gorm.Open(mysql.Open(dsn))
    if err != nil {
        return nil, fmt.Errorf("mysql open, dsn: %s, err: %w", dsn, err)
    }
    sqlDB, err := db.DB()
    if err != nil {
        logs.Errorf("InitDB. db.DB() fail. err:%v", err)
        return nil, err
    }
    // 连接池配置 (高并发关键)
    sqlDB.SetMaxIdleConns(envkey.GetIntD("MYSQL_MAX_IDLE_CONNS", 10))
    sqlDB.SetMaxOpenConns(envkey.GetIntD("MYSQL_MAX_OPEN_CONNS", 100))
    sqlDB.SetConnMaxLifetime(time.Duration(
        envkey.GetIntD("MYSQL_CONN_MAX_LIFETIME", 3600)) * time.Second)
    sqlDB.SetConnMaxIdleTime(time.Duration(
        envkey.GetIntD("MYSQL_CONN_MAX_IDLE_TIME", 600)) * time.Second)
    return db, nil
}
```

**关键调优点**:
- **MaxOpenConns=100**: 控制到 MySQL 的总连接数（防止压垮 DB）
- **MaxIdleConns=10**: 保持 10 个空闲连接（避免频繁创建）
- **ConnMaxLifetime=3600s**: 1 小时强制回收（防 stale 连接）
- **ConnMaxIdleTime=600s**: 10 分钟未用就关闭

### 4.3 Checkpoint 存储 (基于 Redis)

文件路径: `backend/infra/checkpoint/redis.go:1-57`

```go
package checkpoint

import (
    "context"
    "errors"
    "fmt"
    "time"
    "github.com/cloudwego/eino/compose"
    "github.com/coze-dev/coze-studio/backend/infra/cache"
)

type redisStore struct {
    client cache.Cmdable
}

const (
    checkpointKeyTpl = "checkpoint_key:%s"
    checkpointExpire = 24 * 7 * 3600 * time.Second  // 7 天
)

func (r *redisStore) Get(ctx context.Context, checkPointID string) ([]byte, bool, error) {
    v, err := r.client.Get(ctx, fmt.Sprintf(checkpointKeyTpl, checkPointID)).Bytes()
    if err != nil {
        if errors.Is(err, cache.Nil) {
            return nil, false, nil  // 未找到 = 第一次运行
        }
        return nil, false, err
    }
    return v, true, nil
}

func (r *redisStore) Set(ctx context.Context, checkPointID string, checkPoint []byte) error {
    return r.client.Set(ctx, fmt.Sprintf(checkpointKeyTpl, checkPointID),
        checkPoint, checkpointExpire).Err()
}

func NewRedisStore(client cache.Cmdable) compose.CheckPointStore {
    return &redisStore{client: client}
}
```

**Checkpoint 用途**: Eino Graph 的可恢复执行 - 长流程可中断后从 Redis 恢复。

### 5.1 适配器模式 - 5 种 MQ 统一接口

文件路径: `backend/infra/eventbus/impl/kafka/producer.go:1-90`

```go
package kafka

import (
    "context"
    "github.com/IBM/sarama"  // Kafka 客户端
    "github.com/coze-dev/coze-studio/backend/infra/eventbus"
    "github.com/coze-dev/coze-studio/backend/pkg/lang/signal"
    "github.com/coze-dev/coze-studio/backend/pkg/logs"
    "github.com/coze-dev/coze-studio/backend/pkg/safego"
)

type producerImpl struct {
    topic string
    p     sarama.SyncProducer
}

func NewProducer(broker, topic string) (eventbus.Producer, error) {
    config := sarama.NewConfig()
    // 关键配置
    config.Producer.Return.Successes = true   // 等待成功 ack
    config.Producer.Return.Errors = true      // 返回错误
    config.Producer.RequiredAcks = sarama.WaitForAll  // 全部副本确认
    config.Producer.Retry.Max = 5             // 重试 5 次

    producer, err := sarama.NewSyncProducer([]string{broker}, config)
    if err != nil {
        return nil, err
    }
    // 优雅退出
    safego.Go(context.Background(), func() {
        signal.WaitExit()
        if err := producer.Close(); err != nil {
            logs.Errorf("close producer error: %s", err.Error())
        }
    })
    return &producerImpl{topic: topic, p: producer}, nil
}

func (r *producerImpl) Send(ctx context.Context, body []byte, opts ...eventbus.SendOpt) error {
    return r.BatchSend(ctx, [][]byte{body}, opts...)
}
```

### 6.3 RRF (Reciprocal Rank Fusion) 重排序

RRF 是多路召回融合的经典算法，公式:

```
RRF_score(d) = Σ 1 / (k + rank_i(d))
其中 k = 60 (常数), rank_i(d) = 文档 d 在第 i 路召回中的排名
```

```go
// 伪代码示例
func RRFFusion(lists [][]string, k int) []string {
    scores := make(map[string]float64)
    for _, list := range lists {
        for rank, docID := range list {
            scores[docID] += 1.0 / float64(k + rank + 1)
        }
    }
    // 排序
    var sorted []kv
    for k, v := range scores {
        sorted = append(sorted, kv{k, v})
    }
    sort.Slice(sorted, func(i, j int) bool {
        return sorted[i].value > sorted[j].value
    })
    return []string(sorted)  // 返回融合排序后的 ID 列表
}
```

**优势**:
- 无需归一化各路分数（避免不同检索器分数量纲不同）
- 不需要训练
- 经典 BM25 + 向量 + 关键词多路召回融合首选

```python
# backend/infra/coderunner/impl/script/sandbox.py
import subprocess
import resource
import signal

def run_code(code: str, timeout: int = 30) -> dict:
    """在隔离进程执行 Python 代码"""
    # 1. 限制 CPU 时间
    def limit_resources():
        resource.setrlimit(resource.RLIMIT_CPU, (timeout, timeout))
    # 2. 限制内存 (256MB)
    resource.setrlimit(resource.RLIMIT_AS, (256*1024*1024, 256*1024*1024))
    # 3. 禁用网络
    # (通过 namespace/seccomp 实现)
    # 4. 执行
    result = subprocess.run(
        ['python3', '-c', code],
        capture_output=True,
        timeout=timeout,
        preexec_fn=limit_resources,
    )
    return {
        'stdout': result.stdout.decode(),
        'stderr': result.stderr.decode(),
        'returncode': result.returncode,
    }
```

## 十一、ID 生成

文件路径: `backend/infra/idgen/impl/idgen/idgen.go`

```go
// 雪花算法 (Snowflake) - 字节内部改造
type Snowflake struct {
    mu        sync.Mutex
    lastTime  int64
    workerID  int64  // 10 bit
    sequence  int64  // 12 bit
}

func (s *Snowflake) NextID() int64 {
    s.mu.Lock()
    defer s.mu.Unlock()
    now := time.Now().UnixMilli()
    if now == s.lastTime {
        s.sequence = (s.sequence + 1) & 0xFFF  // 4096/ms
    } else {
        s.sequence = 0
    }
    s.lastTime = now
    // 41 bit timestamp | 10 bit worker | 12 bit sequence
    return (now - epoch) << 22 | s.workerID << 12 | s.sequence
}
```

**ID 结构** (64 bit):
- 41 bit 时间戳 (69 年)
- 10 bit 工作机器 ID (1024 个节点)
- 12 bit 序列号 (每毫秒 4096 个)

## 十七、与 AI 直播平台的对比

### 17.1 选型建议

| 组件 | Coze 选型 | AI 直播推荐 | 原因 |
|------|----------|-----------|------|
| HTTP 框架 | Hertz | Gin (中小) / Hertz (大) | Hertz 性能高 |
| ORM | GORM | GORM / Ent | Go 生态首选 |
| 缓存 | Redis | Redis | 业界标准 |
| MQ | Kafka | NATS (轻量) / Kafka (重) | 业务量决定 |
| 向量库 | Milvus/VikingDB | Milvus / Qdrant | 开源优先 |
| LLM 框架 | Eino | Eino / LangChain | 中文场景 Eino 优 |

### 17.2 迁移 Coze 经验的优先级

1. **Hertz 替代 Gin** - 性能提升 2x (QPS)
2. **Eino 替代 LangChain** - 中文支持好 + 类型安全
3. **Vector DB + RRF** - RAG 必备
4. **多 MQ 适配** - 业务增长时灵活切换
5. **PP-Structure** - 文档解析直接用
