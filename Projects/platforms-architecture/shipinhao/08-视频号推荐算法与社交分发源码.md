### 1.2 与抖音/快手推荐的核心差异

| 维度 | 视频号 | 抖音 | 快手 |
|---|---|---|---|
| **主入口** | 关注+朋友+推荐 | 推荐为主 | 关注+推荐 |
| **社交权重** | ⭐⭐⭐⭐⭐ 极高 | ⭐ 几乎无 | ⭐⭐ 较弱 |
| **关注占比** | ~40% | ~5% | ~30% |
| **朋友点赞** | 强信号 | 无 | 弱 |
| **同温层** | 中（社交打破） | 强（信息茧房） | 中 |
| **冷启动策略** | 微信关系链 | 头部 KOL + 广告 | 普惠分发 |
| **算法目标** | 社交关系强化 | 时长 + 互动 | 时长 + 互动 |

**视频号最独特的一点**：**朋友点赞过的视频会作为强信号注入推荐**。**这是抖音/快手都没有的能力**。

## 3. 社交召回：微信关系链的 6 种注入点

> **这是视频号最有特色的召回**——微信关系链是其他平台都没有的"金矿"。

### 3.1 6 种社交注入点

```
┌─────────────────────────────────────────────────────────────┐
│  社交召回的 6 个信号源                                          │
│                                                               │
│  1. 你关注的人发布了新视频        → 强信号 (CTR * 1.5)        │
│  2. 朋友点赞过的视频              → 中强信号 (CTR * 1.2)      │
│  3. 朋友评论过的视频              → 中强信号 (CTR * 1.2)      │
│  4. 朋友在看的直播                → 强信号                     │
│  5. 同一群聊里有人转发            → 极强信号 (CTR * 2.0)      │
│  6. 同一公众号关联的视频          → 中信号                     │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 社交召回的伪代码

```python
# 视频号社交召回（伪代码）
def social_recall(user_id, top_k=200):
    user = get_user(user_id)
    candidates = []
    
    # 1. 关注流（最强信号）
    followees = user.get_followees(limit=100)
    for followee in followees:
        candidates.extend(followee.get_recent_videos(hours=48))
    
    # 2. 朋友点赞流
    friends = user.get_friends(limit=500)  # 微信好友
    for friend in friends:
        liked_videos = friend.get_liked_videos(limit=20, hours=168)  # 一周内
        candidates.extend(liked_videos)
    
    # 3. 朋友评论流
    for friend in friends:
        commented_videos = friend.get_commented_videos(limit=20, hours=168)
        candidates.extend(commented_videos)
    
    # 4. 群聊转发流（极强信号）
    for group in user.get_groups():
        forwarded_videos = group.get_forwarded_videos(limit=10, hours=72)
        candidates.extend(forwarded_videos)
    
    # 5. 公众号关联
    followed_oas = user.get_followed_official_accounts()
    for oa in followed_oas:
        candidates.extend(oa.get_related_videos(limit=5))
    
    # 去重 + 过滤已看 + CTR 预估
    candidates = dedupe(candidates)
    candidates = filter_watched(candidates, user_id)
    candidates = ctr_predict(candidates, user_id)  # 粗打分
    
    return sorted(candidates, key=lambda x: x.ctr_score, reverse=True)[:top_k]
```

### 3.3 群聊转发的特殊处理

**群聊转发是视频号最强的社交信号**——比"朋友点赞"还要强 1.5 倍。原因是：
1. 群聊是"主动推荐"——朋友专门把视频转发给这个群
2. 群内成员关系更紧密（家人/同事/兴趣群）
3. 群内讨论会让用户有"FOMO"心理

```python
# 群聊召回的特殊加权
def group_recall_weight(user_id, video_id):
    # 你所在的每个群都增加权重
    total_weight = 1.0
    user_groups = get_user_groups(user_id)
    for group in user_groups:
        if video_id in group.get_recent_forwarded_videos(hours=72):
            # 每有一个群转发，加 50% 权重
            total_weight *= 1.5
    return min(total_weight, 5.0)  # 最多 5 倍
```

### 3.4 微信关系链的隐私保护

**视频号必须做的隐私保护**：
- 用户 A 点赞了视频 X，但 A 的朋友 B 没有看过 X
- B 看到 X 的"朋友点赞"提示时，**不能暴露 A 的微信昵称/头像**——只能显示"某位微信好友点赞"
- 这就是著名的"匿名社交"机制

```python
# 朋友点赞的匿名展示
def show_friend_likes(video_id, viewer_id):
    likes = get_friend_likes(video_id, viewer_id)  # 拿到所有朋友
    if len(likes) >= 3:
        return "张三、李四、王某 等 12 位好友点赞"  # 显示前几个 + 总数
    elif len(likes) == 2:
        return "张三、李某 等 2 位好友点赞"
    elif len(likes) == 1:
        return "1 位好友点赞"  # 完全匿名
    else:
        return ""
```

## 4. 协同过滤召回：Item2Vec + GraphSAGE

> **视频号除了社交召回，也用经典的协同过滤**——基于"你看过/点赞过的视频"的相似度。

### 4.1 Item2Vec：用过的视频序列训练 item embedding

**Item2Vec** 是 Word2Vec 在推荐场景的迁移——把每个视频当作"词"，把用户观看的视频序列当作"句子"。

```python
# 伪代码：Item2Vec 训练
import torch
import torch.nn as nn

class Item2Vec(nn.Module):
    def __init__(self, num_items, embedding_dim=128):
        super().__init__()
        self.in_emb = nn.Embedding(num_items, embedding_dim)
        self.out_emb = nn.Embedding(num_items, embedding_dim)
    
    def forward(self, center_item, context_items):
        # center_item: [B]
        # context_items: [B, K]
        v = self.in_emb(center_item)  # [B, D]
        u = self.out_emb(context_items)  # [B, K, D]
        logits = (u * v.unsqueeze(1)).sum(dim=-1)  # [B, K]
        return logits

# 训练数据：用户观看的视频序列
# session_1: [v1, v2, v5, v9] -> 用滑动窗口构造 (center, context) 对
# session_2: [v3, v7, v11] -> ...
# 训练 100 个 epoch 后，每个视频有 128 维 embedding
```

### 4.2 Item2Vec 召回的伪代码

```python
# 视频号协同过滤召回
def cf_recall(user_id, top_k=100):
    user = get_user(user_id)
    watch_history = user.get_watch_history(days=30, limit=500)
    
    if len(watch_history) == 0:
        return []  # 冷启动用户交给社交召回
    
    # 1. 拿历史视频的 embedding
    history_embs = item2vec.encode(watch_history)  # [N, 128]
    user_emb = history_embs.mean(dim=0)  # [128]，简单平均
    
    # 2. 在线检索：找最相似的 K 个视频
    #    实际使用 Faiss / Milvus / ScaNN
    similar_videos = faiss_index.search(user_emb, top_k=500)
    
    # 3. 过滤已看
    candidates = filter_watched(similar_videos, user_id)
    
    return candidates[:top_k]
```

### 4.3 GraphSAGE：基于图神经网络的协同过滤

**GraphSAGE** 把用户-视频交互建模成"二部图"，用图神经网络学习 embedding。

```python
# 伪代码：GraphSAGE 双层
class GraphSAGE(nn.Module):
    def __init__(self, num_users, num_items, dim=128):
        super().__init__()
        self.user_emb = nn.Embedding(num_users, dim)
        self.item_emb = nn.Embedding(num_items, dim)
    
    def forward(self, edge_index):
        # edge_index: 2 x E (u-i pairs)
        # 第一层：聚合邻居
        user_emb_1 = self.user_emb
        item_emb_1 = self.item_emb
        
        # 用户侧聚合：u_new = mean([u_emb, sum(i_emb for i in u's neighbors)])
        user_emb_2 = self.aggregate(user_emb_1, item_emb_1, edge_index)
        
        # 物品侧聚合：i_new = mean([i_emb, sum(u_emb for u in i's neighbors)])
        item_emb_2 = self.aggregate(item_emb_1, user_emb_1, edge_index.flip(0))
        
        return user_emb_2, item_emb_2
```

**视频号用 GraphSAGE 的优势**：
- 比 Item2Vec 多用"高阶邻居"信息——比如"你关注的人关注的人也关注 X"
- 可以融合社交关系（朋友也是图上的"边"）
- 冷启动更好（新视频只要有人点赞就能进图）

## 5. 内容召回：双塔模型 + 向量检索

> **双塔模型是现代推荐系统召回的"标配"**——视频号用它做"基于内容"的召回。

### 5.1 双塔模型结构

```
                    ┌──────────┐
                    │ 用户塔    │
                    │          │
  [user_id]    →    │  MLP     │    →    user_emb
  [age, gender] →   │          │
  [历史观看]   →    │          │
                    └──────────┘
                              ↕  (点积 or cosine)
                    ┌──────────┐
                    │ 视频塔    │
                    │          │
  [video_id]    →   │  MLP     │    →    video_emb
  [category]  →     │          │
  [tags]      →     │          │
                    └──────────┘
```

**训练目标**：让"用户看过的视频"的 user_emb × video_emb 接近 1，"没看过的"接近 0。

### 5.2 双塔模型的 PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class TwoTowerModel(nn.Module):
    def __init__(self, num_users, num_videos, user_feat_dim, video_feat_dim, emb_dim=128):
        super().__init__()
        # User tower
        self.user_tower = nn.Sequential(
            nn.Linear(user_feat_dim, 256),
            nn.ReLU(),
            nn.BatchNorm1d(256),
            nn.Dropout(0.2),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, emb_dim),
        )
        # Video tower
        self.video_tower = nn.Sequential(
            nn.Linear(video_feat_dim, 256),
            nn.ReLU(),
            nn.BatchNorm1d(256),
            nn.Dropout(0.2),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, emb_dim),
        )
        # Temperature
        self.temperature = nn.Parameter(torch.tensor(0.07))
    
    def forward(self, user_feat, video_feat):
        u = F.normalize(self.user_tower(user_feat), dim=-1)
        v = F.normalize(self.video_tower(video_feat), dim=-1)
        # cosine 相似度
        logits = (u @ v.T) / self.temperature
        return logits
```

**在线检索时**，不能对全量视频（百万到亿级）算相似度——需要 ANN 索引。

## 6. 粗排：轻量级双塔打分

> **粗排的目标是用尽量少的算力把 1000+ 候选筛到 200**——视频号用"轻量版"的双塔模型。

### 6.1 粗排 vs 召回双塔的差异

| 维度 | 召回双塔 | 粗排双塔 |
|---|---|---|
| 候选量 | 10,000 → 1,000 | 1,000 → 200 |
| 模型大小 | 极小（128 dim） | 中等（256 dim） |
| 特征 | 简化 | 更多 |
| 时延 | < 1ms | 1-3ms |
| 训练数据 | 曝光未点击 | 曝光 + 点击 |
| 是否端到端 | 离线算好灌库 | 在线打分 |

### 6.2 粗排模型简化实现

```python
class LightTwoTower(nn.Module):
    """粗排专用：比召回模型大一点"""
    def __init__(self, num_users, num_videos, emb_dim=64):
        super().__init__()
        self.user_emb = nn.Embedding(num_users, emb_dim)
        self.video_emb = nn.Embedding(num_videos, emb_dim)
        # 加入一些交叉特征
        self.cross = nn.Linear(emb_dim * 2 + 5, 1)  # +5 个统计特征
    
    def forward(self, user_id, video_id, stats):
        u = self.user_emb(user_id)
        v = self.video_emb(video_id)
        # 拼接 + 简单线性
        feat = torch.cat([u, v, stats], dim=-1)
        score = torch.sigmoid(self.cross(feat))
        return score

# stats: [like_count, comment_count, share_count, ctr, cvr]
```

## 7. 精排：DCN + Wide&Deep

> **视频号精排用的"DCN + Wide&Deep"是工业界最主流的精排模型**。精排要做到"准确 + 公平"——不能光看 CTR，还要兼顾多样性、社交信号等。

### 7.1 DCN（Deep & Cross Network）

**DCN 核心**：用 Cross Network 自动学习特征交叉，避免人工设计。

```python
class CrossNetwork(nn.Module):
    def __init__(self, input_dim, num_layers=3):
        super().__init__()
        self.num_layers = num_layers
        self.W = nn.ParameterList([nn.Parameter(torch.randn(input_dim, 1)) for _ in range(num_layers)])
        self.b = nn.ParameterList([nn.Parameter(torch.zeros(input_dim)) for _ in range(num_layers)])
    
    def forward(self, x0):
        x = x0
        for i in range(self.num_layers):
            x = x0 * (x @ self.W[i]) + self.b[i] + x
        return x

class DCN(nn.Module):
    def __init__(self, num_features, emb_dim=128, cross_layers=3, deep_layers=[256, 128, 64]):
        super().__init__()
        self.embedding = nn.Linear(num_features, emb_dim)  # 简化
        self.cross = CrossNetwork(emb_dim, cross_layers)
        self.deep = nn.Sequential(
            nn.Linear(emb_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
        )
        self.final = nn.Linear(emb_dim + 64, 1)
    
    def forward(self, x):
        emb = self.embedding(x)
        cross_out = self.cross(emb)
        deep_out = self.deep(emb)
        out = torch.cat([cross_out, deep_out], dim=-1)
        return torch.sigmoid(self.final(out))
```

### 7.2 Wide&Deep：记忆 + 泛化

**Wide 部分**：线性模型 + 人工交叉特征（如"AND(age<25, gender=female)"）
**Deep 部分**：DNN 自动学习高阶特征

```python
class WideDeep(nn.Module):
    def __init__(self, num_features, num_cross_features):
        super().__init__()
        # Wide: 简单线性 + 交叉特征
        self.wide = nn.Linear(num_features + num_cross_features, 1)
        # Deep: DNN
        self.deep = nn.Sequential(
            nn.Linear(num_features, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 1),
        )
    
    def forward(self, x, cross_x):
        wide_out = self.wide(torch.cat([x, cross_x], dim=-1))
        deep_out = self.deep(x)
        return torch.sigmoid(wide_out + deep_out)
```

**多任务学习**（MMoE / PLE）：

```python
class MMoE(nn.Module):
    """Multi-gate Mixture-of-Experts"""
    def __init__(self, num_experts=8, expert_dim=256, num_tasks=7, input_dim=1024):
        super().__init__()
        # 多个专家网络
        self.experts = nn.ModuleList([
            nn.Sequential(nn.Linear(input_dim, expert_dim), nn.ReLU(), nn.Linear(expert_dim, expert_dim))
            for _ in range(num_experts)
        ])
        # 每个任务的门控
        self.gates = nn.ModuleList([
            nn.Linear(input_dim, num_experts) for _ in range(num_tasks)
        ])
        # 每个任务的 tower
        self.towers = nn.ModuleList([
            nn.Sequential(nn.Linear(expert_dim, 64), nn.ReLU(), nn.Linear(64, 1), nn.Sigmoid())
            for _ in range(num_tasks)
        ])
    
    def forward(self, x):
        # 1. 所有专家计算
        expert_outs = torch.stack([e(x) for e in self.experts], dim=1)  # [B, E, D]
        # 2. 每个任务门控
        task_outs = []
        for gate, tower in zip(self.gates, self.towers):
            gate_w = F.softmax(gate(x), dim=-1)  # [B, E]
            mixed = (expert_outs * gate_w.unsqueeze(-1)).sum(dim=1)  # [B, D]
            task_outs.append(tower(mixed))
        return task_outs  # [ctr, like, comment, share, watch_time, follow, live_enter]
```

```python
def diversity_rerank(videos, top_k=10):
    selected = []
    category_count = defaultdict(int)
    uploader_count = defaultdict(int)
    
    # 按精排分数降序
    for v in sorted(videos, key=lambda x: x.score, reverse=True):
        # 同类目相邻限制
        if category_count[v.category] >= 2:
            continue  # 同类目最多 2 个相邻
        
        # 同作者限制
        if uploader_count[v.uploader_id] >= 1:
            continue  # 同作者最多 1 个
        
        # 时长打散
        if len(selected) > 0 and abs(selected[-1].duration - v.duration) < 10:
            continue  # 避免连续 2 个都是短视频或都是长视频
        
        selected.append(v)
        category_count[v.category] += 1
        uploader_count[v.uploader_id] += 1
        
        if len(selected) >= top_k:
            break
    
    return selected
```

### 9.2 关注扩散：朋友间传播

```python
def viral_diffusion(video, max_hops=3):
    """BFS 模拟视频的裂变传播"""
    exposed = set()
    current_hop = {video.uploader_id}  # 第 0 跳
    
    for hop in range(1, max_hops + 1):
        next_hop = set()
        for user_id in current_hop:

                if friend in exposed:
                    continue
                if probability_will_like(friend, video) > 0.3:
```

```python
class OnlineTrainer:
    """流式训练：每来一条数据就更新模型"""
    def __init__(self, model, lr=0.001):
        self.model = model
        self.optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    
    def on_sample(self, user_id, video_id, label):
        # 1. 拿一个样本（来自 Kafka）
        # 2. 前向
        pred = self.model(user_id, video_id)
        # 3. 损失
        loss = F.binary_cross_entropy(pred, label)
        # 4. 反向
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()
        return loss.item()
```

```python
# 伪代码：Monolith HashTable
class EmbeddingHashTable:
    def __init__(self, num_embeddings, embedding_dim):
        self.table = np.zeros((num_embeddings, embedding_dim), dtype=np.float32)
        self.lock = threading.RLock()  # 多线程安全
    
    def lookup(self, ids):
        with self.lock:
            return self.table[ids]  # O(1) 查表
    
    def update(self, ids, grads, lr=0.001):
        with self.lock:
            # 同步 SGD
            for id, grad in zip(ids, grads):
                self.table[id] -= lr * grad
```
