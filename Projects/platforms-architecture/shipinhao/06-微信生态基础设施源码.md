### 1.2 微信生态的"分层"思想

| 层级 | 职责 | 关键文件 |
|------|------|----------|
| **Variable** | 设计 token (颜色/间距/字号) | `variable/*.less` |
| **Mixin** | 复用方法 (1px/loading/arrow) | `mixin/*.less` |
| **Base** | reset + 全局基础样式 | `base/*.less` |
| **Widget** | 业务组件 (button/cell/dialog) | `widget/*/` |
| **Theme** | 主题切换 (light/dark/care) | `theme/vars/` |

## 二、主题系统 (light/dark/care) - 微信生态核心抽象

### 2.1 设计 Token 抽象

文件路径: `src/style/base/variable/color.less:1-49`

```less
@import "../theme/index";

// 通过 setColor 抽象颜色映射（自动适配 light/dark）
.setColor(--weui-BG-COLOR-ACTIVE, #ececec, overlay(rgba(255, 255, 255, 0.05), #2c2c2c));

// 主色与警示色
@weuiColorPrimary: var(--weui-BRAND);   // 品牌色 = CSS 变量
@weuiColorWarn: var(--weui-RED);        // 警示色 = CSS 变量

// active 状态蒙层
@weuiActiveMaskBlack: rgba(0, 0, 0, 0.15);

// 链接色
@weuiLinkColorDefault: var(--weui-LINK);

// 背景色
@weuiBgColorDefault: var(--weui-BG-0);    // 一级背景
@weuiBgColorPrimary: var(--weui-BG-1);    // 二级背景
@weuiBgColorActive:  var(--weui-BG-COLOR-ACTIVE);

// 描边色
@weuiLineColorLight: var(--weui-FG-3);
@weuiLineColorDark:  var(--weui-FG-2);

// 文字色
@weuiTextColorTitle: var(--weui-FG-0);  // 标题（最深）
@weuiTextColorDesc:  var(--weui-FG-1);  // 描述
@weuiTextColorTips:  var(--weui-FG-2);  // 提示（最浅）
@weuiTextColorWarn:  @weuiColorWarn;
```

**核心思想**: 业务组件只引用 `var(--weui-FG-0)` 等 CSS 变量，**实际颜色值在主题层定义**，切换主题只换 `:root` 的 CSS 变量即可。

### 2.2 setColor mixin 源码

文件路径: `src/style/base/theme/fn.less` (节选)

```less
// 主题切换的核心 mixin
.setColor(@name, @lightValue, @darkValue) {
  // 默认 light
  @{name}: @lightValue;
  // 媒体查询自动切换到 dark
  @media (prefers-color-scheme: dark) {
    @{name}: @darkValue;
  }
}

// 颜色叠加（用于"在背景上覆盖一层透明度"）
.overlay(@color, @bg) {
  // 计算 alpha 合成
  // 浅色: alpha 0.05 + 白底
  // 深色: 固定深灰 #2c2c2c
}
```

### 4.2 Radio / Checkbox 源码

文件路径: `src/style/widget/weui-cell/weui-check/weui-radio.less:1-42`

```less
@import "../../../base/fn";

// method2 accessibility - a11y 优化
.weui-cells_radio {
  .weui-cell__ft {
    padding-left: @weuiCellInnerGapH;
    font-size: 0;  // 隐藏原生 radio（保留可访问性）
  }
}

.weui-check {
  // radio 样式（复选/单选共用）
  .weui-cells_radio & {
    & + .weui-icon-checked {
      min-width: 16px;
      color: transparent;  // 默认透明
    }
    // 选中态
    &:checked,
    &[aria-checked="true"] {
      & + .weui-icon-checked {
        color: @weuiColorPrimary;
        // 勾选 SVG 嵌入 data URI
        mask-image: url(data:image/svg+xml,%3Csvg%20width%3D%2224%22%20height%3D%2224%22...);
      }
    }
  }
}
```

**a11y 关键点**:
- 不使用 `display:none` 隐藏原生 input（屏幕阅读器无法读到）
- 改用 `font-size: 0` 让原生控件消失，但 DOM 仍可读
- 状态用 `aria-checked="true"` 而非 `:checked`（对屏幕阅读器更友好）
- 勾选图标用 `mask-image` + `currentColor`，主题切换时自动变色

### 5.3 Loading 加载器

```less
@import "../../base/fn";
@import "./weui-primary-loading";

.weui-loading {
  font-size: 16px;
  width: 1em;
  height: 1em;
  display: inline-block;
  vertical-align: middle;
  // 双弧形 SVG 旋转动画（data URI 内嵌）

  background-size: 100%;

  // 透明版（用于白底场景）
  &.weui-loading_transparent,
  &.weui-icon_toast,
  .weui-btn_loading.weui-btn_primary & {
    background-image: url("data:image/svg+xml,%3Csvg...%3E");
  }
}

.weui-mask-loading {
  display: inline-block;
  vertical-align: middle;
  font-size: 16px;
  width: 1em;
  height: 1em;
  // mask 实现 - 用 currentColor 即可变色
  mask: url("data:image/svg+xml,...") 0 0 no-repeat;
  mask-size: cover;
  background-color: currentColor;
  color: #606060;
}

@keyframes weuiLoading {
  0%   { transform: rotate3d(0, 0, 1, 0deg); }
  100% { transform: rotate3d(0, 0, 1, 360deg); }
}
```

**关键设计**:
- Loading 用**内嵌 SVG data URI** 而非外链文件（省 HTTP 请求）
- `mask-image` + `currentColor` 实现**可变色**的图标
- `font-size: 16px` + `em` 单位 → 通过修改 `font-size` 即可缩放


**纯 CSS 实现旋转 Loading** - 不依赖任何 JS 或 GIF。
- 关键技巧：`steps(60, end)` 让动画**离散成 60 步** → 视觉上像刻度盘转动
- `mask-image: linear-gradient` 让弧线有"淡入淡出"效果

## 六、1px 边框解决方案 (WeUI 的招牌 mixin)

文件路径: `src/style/base/mixin/setOnepx.less`

```less
// 上边框
.setTopLine(@c: var(--weui-FG-3)) {
  content: " ";
  position: absolute;
  left: 0;
  right: 0;
  height: 1px;
  top: 0;
  border-top: 1px solid @c;
  transform-origin: 0 0;
  // 关键: 0.5 倍缩放，适配 retina 屏
  transform: scaleY(0.5);
}

// 下边框
.setBottomLine(@c: var(--weui-FG-3)) {
  content: " ";
  position: absolute;
  left: 0;
  right: 0;
  height: 1px;
  bottom: 0;
  border-bottom: 1px solid @c;
  transform-origin: 0 100%;
  transform: scaleY(0.5);
}

// 左右同理
.setLeftLine(@c: var(--weui-FG-3)) {
  content: " ";
  position: absolute;
  top: 0;
  bottom: 0;
  width: 1px;
  left: 0;
  border-left: 1px solid @c;
  transform-origin: 0 0;
  transform: scaleX(0.5);
}
```

**为什么需要 0.5 倍？**
- 普通屏幕 1 CSS px = 1 物理像素
- retina 屏幕 1 CSS px = 2 物理像素
- 实际边框设为 `1px` 物理像素时 CSS 是 `0.5px`
- 浏览器无法渲染 `0.5px`（早期）→ 用 `1px` + `scaleY(0.5)` 模拟

## 十二、关键设计总结

### 12.1 WeUI 的 7 大设计原则

| 原则 | 体现 |
|------|------|
| **设备适配** | 1px 边框、env(safe-area-inset-*) |
| **主题切换** | CSS 变量 + media query 自动跟随系统 |
| **无障碍** | aria-checked、focus-visible、a11y 隐藏类 |
| **性能优化** | SVG data URI 内嵌、纯 CSS 动画 |
| **BEM 命名** | weui-block__element--modifier |
| **按需引入** | 每个组件可单独 import，无打包负担 |
| **Material Design 兼顾** | 阴影、圆角、active 态 |

### 12.2 微信生态 CSS 架构

```
设计 Token (CSS 变量)
       ↓
   主题切换 (light/dark/care)
       ↓
   Mixin (1px/arrow/loading)
       ↓
   基础样式 (reset/base)
       ↓
   业务组件 (button/cell/dialog)
       ↓
   业务页面 (视频号/公众号/小程序)
```

这种分层让 **"一套样式跑 50+ 业务"** 成为可能。
