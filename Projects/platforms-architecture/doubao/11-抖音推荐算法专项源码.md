## 三、无碰撞 Embedding 表 (核心创新 1)

### 3.1 问题: 哈希冲突
```
传统做法 (TensorFlow native):
    id → hash(id) % bucket_size → embedding[bucket]

问题:
  - 100 万 ID 哈希到 10 万 bucket, 必有冲突
  - "用户 12345" 和 "商品 67890" 可能落在同一 bucket
  - 共享同一 Embedding, 模型精度损失
```

### 3.2 Monolith 方案: 完整 ID 映射
```
Monolith 方案:
    id → hash(id) % INT64_MAX → 独立 slot → embedding

特点:
  - 每个 ID 都有独立 slot (不共享)
  - 通过 64-bit MurmurHash + slot 分配
  - 内存换精度 (Tradeoff: 内存 ×2, 精度 +5-10%)
```

```python
class BaseHashTable(abc.ABC):
  """
  The base class for the hash table.

  For the write operation, it will return a new HashTable. This makes it easier
  to chain operations that need to use the updated tables. User can use this
  behavior to balance the parallelism and the data freshness.
  """

  @abc.abstractmethod
  def assign(self,
             ids: tf.Tensor,
             values: tf.Tensor,
             req_time: tf.Tensor = None) -> "BaseHashTable":
    """
    Assign values to |id| entry in hash table.
    ids - a 1D tensor represents which entry should be added by value
    values - a 2D tensor. The first dim should equal to ids's length, the second dim should
    equal to hash_table's dim size.

    Returns updated hash table.
    """
    pass

  @abc.abstractmethod
  def assign_add(self,
                 ids: tf.Tensor,
                 values: tf.Tensor,
                 req_time: tf.Tensor = None) -> "BaseHashTable":
    """Assign add values to |id| entry in hash table."""
    pass

  @abc.abstractmethod
  def lookup(self,
             ids: tf.Tensor,
             use_multi_threads=False,
             enable_dedup=False) -> tf.Tensor:
    """
    Look up the embeddings in hash table. The embedding will be summed up in the same batch.

    ids - a 1D int64 tensor

    use_multi_threads - True if the caller wants to lookup using multi-threads.

    enable_dedup - True if the caller wants to lookup without duplicate ids

    Returns a 2-D tensor which maps id to embeddings.
    """
    pass

  @property
  @abc.abstractmethod
  def dim_size(self):
    pass

  @abc.abstractmethod
  def apply_gradients(self,
                      ids: tf.Tensor,
                      grads: tf.Tensor,
                      global_step: tf.Tensor,
                      use_multi_threads=False,
                      enable_dedup=False,
                      req_time: tf.Tensor = None) -> "BaseHashTable":
    """Applies the gradients with respect to the ids."""
    pass

  @abc.abstractmethod
  def as_op(self) -> Union[tf.Tensor, tf.Operation]:
    """
    Convert hash table to an op or tensor. Useful to do the dependency control.
    """
    pass
```

```cpp
// C:\Users\15389\source\monolith\monolith\native_training\runtime\hash_table\embedding_hash_table.cc
// 简化的核心逻辑 (实际在 C++ 实现)
class EmbeddingHashTable {
public:
  // 无碰撞 slot 分配
  Status GetSlot(int64_t id, int64_t* slot) {
    // 1. MurmurHash3 64-bit
    uint64_t hash = MurmurHash3(id);
    // 2. 分配独立 slot (不取模!)
    *slot = AllocateSlot(hash);
    return OkStatus();
  }

  // Embedding 查找
  Status Lookup(int64_t id, float* embedding) {
    int64_t slot;
    GetSlot(id, &slot);
    // 3. 直接读取 slot 对应 embedding
    return ReadSlot(slot, embedding);
  }
};
```

| 参数 | 数值 | 说明 |

## 四、分布式参数服务器 (核心创新 2)

### 4.1 为什么需要 PS
```
训练数据规模:
  - 抖音每天 1000 亿+ 样本
  - 单机训练: 1 个 epoch = 1 个月 (不可接受)
  - 必须分布式

Embedding 规模:
  - 10 亿 ID × 128 维 × 4 字节 = 512 GB (单 Embedding 表)
  - 单机显存/内存放不下
  - 必须分片到多机

参数服务器 (PS):
  - 存储 Embedding (高内存)
  - 训练 Worker (高算力)
  - 两者分离, 各自扩展
```

```python
def ragged_split_by_indices(
    indices: tf.Tensor, num: tf.RaggedTensor,
    num_splits: int) -> Tuple[List[tf.RaggedTensor], List[tf.RaggedTensor]]:
  """
  Split a int64 ragged tensor into |num_splits| ragged tensor based on indices.

  For example,
  indices = [0, 1, 0, 1]
  num = [[4, 3, 2], [1]]
  num_splits = 2
  ===>
  [
    [[4, 2], []],
    [[3], [1]],
  ],
  [
    [[0, 2], []],
    [[1], [3]],
  ]
  """
  splitted_num, splitted_num_splits, splitted_pos = gen_distribution_ops.monolith_ragged_split_by_indices(
      indices, num.values, num.row_splits, num_splits=num_splits)
  results = []
  pos = []
  for i in range(num_splits):
    results.append(
        tf.RaggedTensor.from_row_splits(splitted_num[i],
                                        splitted_num_splits[i],
                                        validate=False))
    pos.append(
        tf.RaggedTensor.from_row_splits(splitted_pos[i],
                                        splitted_num_splits[i],
                                        validate=False))
  return results, pos
```

### 5.2 Batched Sparse Tensor 优势
- 一次 batch 包含 1024-4096 个样本的稀疏 ID
- 减少 PS 通信次数 (从 1M 次降到 1K 次)
- 减少 Lookup 重复 ID (enable_dedup=True)

```python
class Combiner:
  """Pooling 策略基类"""
  def __init__(self, name):
    self.name = name

  def __call__(self, embeddings, weights=None, flatten=False):
    raise NotImplementedError


class SumCombiner(Combiner):
  """Sum Pooling: e = sum(e_i)"""
  def __call__(self, embeddings, weights=None, flatten=False):
    if weights is None:
      return tf.reduce_sum(embeddings, axis=-2)
    return tf.reduce_sum(embeddings * weights, axis=-2)


class MeanCombiner(Combiner):
  """Mean Pooling: e = mean(e_i)"""
  def __call__(self, embeddings, weights=None, flatten=False):
    if weights is None:
      return tf.reduce_mean(embeddings, axis=-2)
    weights_sum = tf.reduce_sum(weights, axis=-1, keepdims=True)
    return tf.reduce_sum(embeddings * weights, axis=-2) / (weights_sum + 1e-9)
```

```python
      user_tower = tf.layers.dense(user_tower, 64)  # 64 维向量

      labels = features["label"]
      loss = tf.losses.sigmoid_cross_entropy(labels, similarity)
```

### 12.2 DCN + Wide&Deep + MMoE 精排

```python
# 抖音精排模型简化版
class DCNWideDeepMMoE(NativeTask):
  def create_model_fn(self):
    def model_fn(features, mode, config):
      # 1. Embedding 层
      embeddings = self._lookup_all_slots(features)
      concat = tf.concat(embeddings, axis=-1)  # [B, 6*128=768]

      # 2. Wide 部分 (LR)
      wide_logits = tf.layers.dense(concat, 1)

      # 3. DCN 部分 (Cross Network)
      cross = concat
      for i in range(3):  # 3 层 Cross
        cross = cross * tf.layers.dense(cross, 768) + cross
        # x_{l+1} = x_0 ⊙ (W_l · x_l + b_l) + x_l

      # 4. Deep 部分 (DNN)
      deep = tf.layers.dense(concat, 1024, activation=tf.nn.relu)
      deep = tf.layers.dense(deep, 512, activation=tf.nn.relu)
      deep = tf.layers.dense(deep, 256, activation=tf.nn.relu)
      deep_logits = tf.layers.dense(deep, 1)

      # 5. MMoE (7 个专家 → 7 个任务)
      expert_outputs = []
      for i in range(7):  # 7 个专家
        expert = tf.layers.dense(concat, 256, activation=tf.nn.relu)
        expert_outputs.append(expert)
      expert_stack = tf.stack(expert_outputs, axis=1)  # [B, 7, 256]

      task_names = ["ctr", "like", "comment", "share", "follow", "watch_time", "live_enter"]
      task_logits = {}
      for task in task_names:
        # Gate 网络
        gate = tf.nn.softmax(tf.layers.dense(concat, 7), axis=-1)
        # 加权组合
        weighted = tf.reduce_sum(expert_stack * tf.expand_dims(gate, -1), axis=1)
        # 任务头
        task_logits[task] = tf.layers.dense(weighted, 1)

      # 6. 组合最终 logits
      final_logits = (
        wide_logits +
        cross_logits +
        deep_logits +
        sum(task_logits.values()) * 0.1
      )

      # 7. Loss
      labels = features["label"]
      loss = tf.losses.sigmoid_cross_entropy(labels, final_logits)
      return tf.estimator.EstimatorSpec(mode=mode, loss=loss, train_op=...)
    return model_fn
```

```python
    # 阶段 4: 100% 流量 (爆款)
```

```python
    scores, ids = self.index.search(np.array([user_emb]), top_k)
    return list(zip(ids[0], scores[0]))

# 阶段 2 (规模化): Monolith 风格
class MonolithStyleRecommender:
  def __init__(self):
    # 无碰撞 HashTable
    self.embedding_table = CollisionlessHashTable(dim_size=128)
    # 分布式 PS
    self.ps = DistributedPS(ps_num=10)
    # Kafka 实时数据
    self.kafka_consumer = KafkaConsumer("user_behavior")

  def train_realtime(self):
    while True:
      samples = self.kafka_consumer.poll()
      self.update_embeddings(samples)
      if time.time() % 60 == 0:
        self.sync_to_online()
```

### 16.3 AI 直播 + Monolith 风格
- **直播间 Embedding**: 直播间 ID, 主播 ID, 标签 → 128 维
- **用户 Embedding**: 用户 ID, 历史行为 → 128 维

## 十八、常见问题与解决方案

### 18.1 内存爆炸
**问题**: 10 亿 ID × 128 维 × 4 字节 = 512 GB Embedding
**解决方案**:
1. FP16 压缩 (内存减半, 损失 < 1% 精度)
2. INT8 量化 (内存减 4 倍, 损失 < 3% 精度)
3. 分片到多 PS (单 PS < 128 GB)
4. HBM 存储 (A100 80GB HBM)

### 18.2 训练慢
**问题**: 1 epoch 1000 亿样本 → 1 周
**解决方案**:
1. 异步训练 (Monolith 默认)
2. Horovod 分布式 (AllReduce)
3. 混合精度 (FP16 + FP32)
4. 流水线 (Pipeline Parallelism)

### 18.3 实时性 vs 稳定性
**问题**: 分钟级更新可能引入模型抖动
**解决方案**:
1. A/B 测试 (10% 流量新模型)
2. 渐进式发布 (1% → 10% → 50% → 100%)
3. 监控指标 (CTR / 完播率 / 互动率)
4. 自动回滚 (指标下降 > 5% 立即回滚)

## 二十一、附录 B: 关键公式

### 21.1 DCN Cross Network
```
x_{l+1} = x_0 ⊙ (W_l · x_l + b_l) + x_l

其中:
  x_0: 输入
  x_l: 第 l 层输出
  W_l, b_l: 第 l 层参数
  ⊙: 元素积
```

### 21.2 Wide&Deep
```
P(y=1|x) = σ(w_wide · x + w_deep · a^(l) + b)

其中:
  Wide: 记忆 (Memorization) - LR
  Deep: 泛化 (Generalization) - DNN
```

### 21.3 MMoE
```
y_k = h_k(∑_i g_i(x) · f_i(x))

其中:
  f_i: 第 i 个专家网络
  g_i: 第 i 个 Gate 网络
  h_k: 第 k 个任务头
  k: 任务数 (抖音 7 个)
```

### 21.4 Cosine 相似度 (双塔)
```
sim(u, v) = (u · v) / (||u|| × ||v||)

其中:
  u: 用户向量
  v: 视频向量
```
