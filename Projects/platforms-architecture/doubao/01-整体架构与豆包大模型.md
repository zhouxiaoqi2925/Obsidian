### 3.2 Doubao-1.5-Pro（旗舰）

**核心规格**（基于公开技术报告与火山引擎文档）：

- **架构**：MoE（Mixture of Experts），256 个专家路由
- **总参数**：约 200B+
- **激活参数**：约 20B（每个 token 仅激活部分专家）
- **上下文窗口**：128K tokens（Pro 标准版）、256K tokens（Pro-256k）
- **训练数据**：截止 2024 年中，覆盖中英双语
- **推理吞吐**：是上一代 Doubao-Pro 的 1.8 倍（来源：火山引擎 2024 Q4 发布）
- **价格**：输入 0.8 元/百万 tokens，输出 2 元/百万 tokens（火山引擎 2025 年公开报价）

### 3.3 MoE 架构详解

字节豆包采用了与 GPT-4 类似思路的 **稀疏 MoE 架构**：

```python
# MoE 路由简化示例（基于公开论文精神，非字节官方）
import torch
import torch.nn.functional as F

class MoERouter(torch.nn.Module):
    """简化版专家路由，豆包使用类似的 Top-K 路由"""
    def __init__(self, hidden_dim, num_experts=256, top_k=8):
        super().__init__()
        self.gate = torch.nn.Linear(hidden_dim, num_experts)
        self.num_experts = num_experts
        self.top_k = top_k
    
    def forward(self, hidden_states):
        # [batch, seq_len, hidden_dim] -> [batch*seq_len, hidden_dim]
        x = hidden_states.view(-1, hidden_states.size(-1))
        # 路由得分
        router_logits = self.gate(x)
        # Top-K 专家选择
        routing_weights = F.softmax(router_logits, dim=-1)
        topk_weights, topk_idx = torch.topk(routing_weights, self.top_k, dim=-1)
        # 归一化
        topk_weights = topk_weights / topk_weights.sum(dim=-1, keepdim=True)
        return topk_weights, topk_idx
```

**MoE 优势**：
- 总参数量大（200B+），但单次推理只激活部分（20B）
- 训练效果好（参数多=知识库大）
- 推理成本低（激活少=算力少）

### 3.4 Doubao-1.5-Lite（轻量）

- **架构**：Dense（非 MoE）
- **参数**：约 7B
- **上下文**：32K tokens
- **场景**：实时对话、低延迟、端侧推理
- **价格**：输入 0.3 元/百万 tokens（约为 Pro 的 1/3）
- **基准**：MMLU 70+、C-Eval 75+（具体数值以官方发布为准）

### 3.5 Doubao-Character（角色扮演）

- 基于 Pro 基座 + SFT + RLHF 微调
- 专长：情感对话、人设一致性、记忆
- 典型应用：豆包 App 的 "AI 朋友"、情感陪伴
- 关键技术：长期记忆、情感识别、个性化回复

### 3.6 Doubao-Embedding

- **维度**：1024 / 2048 可选
- **最大输入**：8192 tokens
- **支持语言**：中英双语为主，100+ 语言
- **基准性能**（来源：火山引擎官方）：
  - MTEB 中文榜 Top 3
  - C-MTEB 检索任务 SOTA
- **价格**：0.5 元/百万 tokens

### 3.7 视觉/语音模型

**Doubao-Vision / Seed-VL**：
- 输入：图像 + 文本
- 输出：文本（图像描述、OCR、视觉问答）
- 支持分辨率：最高 4K
- 应用于：电商商品理解、内容审核、图文问答

**Seed-ASR**：
- 中文普通话识别 SOTA（据火山引擎发布）
- 支持方言：粤语、上海话、四川话等
- 实时流式识别 + 说话人分离

**Seed-TTS**：
- 语音克隆：5 秒音频即可克隆
- 多语种：中文、英文、日语、韩语
- 情感控制：高兴/悲伤/愤怒/中性

```python
# Python SDK 调用豆包 API

client = Ark(
    api_key="YOUR_ARK_API_KEY",
```

```go
// Go SDK 调用豆包 API
package main

import (
    "context"
    "fmt"
    "github.com/volcengine/volcengine-go-sdk/service/ark"
)

func main() {
    client := ark.NewClientWithAccessKey("cn-beijing", "AK", "SK")

        return

}
```

## 5. 训练与数据

### 5.1 数据规模

- **预训练 tokens**：数万亿级别（业内估算 10T+）
- **数据来源**：抖音/今日头条/西瓜视频等内部 UGC + 公开语料
- **数据清洗**：自研 Dolphin 质量过滤系统

### 5.2 训练基础设施

- **GPU 集群**：万卡级 H800 / H100（2024 年公开报道）
- **训练框架**：自研 + 兼容 Megatron-LM / DeepSpeed
- **并行策略**：3D 并行（TP + PP + DP）+ ZeRO
- **通信库**：Bagua（字节自研，已开源）

### 5.3 Bagua 分布式训练

```python
# Bagua 分布式训练简化示例
import bagua.torch_api as bagua

# 初始化 Bagua
bagua.init()

# 构建模型 + optimizer

optimizer = ...

# 用 Bagua 包装
```

**Bagua 特色**：
- 字节自研高性能分布式训练通信库
- 支持 AllReduce、AllGather、ReduceScatter 等多种通信原语
- 在万卡规模下相比 NCCL 有 10-30% 性能提升（字节公开测试数据）
