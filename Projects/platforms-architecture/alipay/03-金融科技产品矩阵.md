## 3.2 余额宝（天弘增利宝货币基金）

### 3.2.1 产品本质

**余额宝 ≠ 银行存款，本质是天弘增利宝货币基金（基金代码 000198）**。

```text
  用户视角: 充值 → 余额宝 → 收益 → 支付
  实际链路:
  ┌──────┐    申购      ┌──────┐   投资     ┌────────┐
  │ 用户 │ ───────────► │余额宝│ ──────────►│货币基金│
  │      │              │账户  │            │ 资产池 │
  └──────┘              └──────┘            └────────┘
   1元=1基金份额                收益来源于:
                                1) 银行存款 (30-50%)
                                2) 短期债券 (30-40%)
                                3) 央行票据
```

### 3.2.2 关键数据

### 3.2.4 大规模并发难点

- **大促凌晨 0 点**抢购（"10 分钟售罄"），QPS 峰值 **>10 万**
- 解决：分库分表 + 限流削峰 + 异步排队
- 资金安全：**保险承保 + 存款保险 + 基金托管**

```java
// 余额宝申购核心逻辑
public BalanceBaoResult purchase(String userId, long amount) {
    // 1. 实名 + 风险评估
    if (!riskService.hasAssessed(userId)) {
        throw new NeedRiskAssessException();
    }
    // 2. 单笔限额
    if (amount > SINGLE_LIMIT) throw new LimitException();
    // 3. 单日累计
    if (dailySum(userId) + amount > DAILY_LIMIT) throw new DailyLimitException();
    // 4. 余额扣减 (强一致)
    accountService.debit(userId, amount, BizType.YUE_BAO_PURCHASE);
    // 5. 调天弘 TA 系统申购
    TaResult ta = tianhongTA.purchase(userId, amount);
    // 6. 写交易流水 + 异步通知
    recordJournal(userId, amount, ta);
    return BalanceBaoResult.from(ta);
}
```

## 3.3 花呗（消费金融 / 信用支付）

### 3.3.1 产品本质

**花呗 = 蚂蚁消费金融提供的虚拟信用卡**。

```text
  花呗资金流
  ┌──────┐ 消费 ┌────────┐  请款 ┌────────┐
  │ 用户 │ ───► │ 商户   │  ────► │花呗/消金│
  │      │      │        │        │ 公司   │
  └──────┘      └────────┘        └────┬───┘
   ↑                                    │
   │ 30 天免息/分期还款                  │ 资金来源
   └────────────────────────────────────┘
       ├─ 自有资金
       ├─ ABS 资产证券化 (花呗分期 ABS)
       └─ 银行联合贷款 (蚂蚁+银行)
```

### 3.3.2 业务关键指标（公开披露）

| 指标 | 数值 | 时点 |
|---|---|---|
| 用户数 | **>5 亿** | 2021（招股书）|
| 余额规模 | **>1.7 万亿** | 2021（招股书）|
| 30 天免息期 | 30 天 | 默认 |
| 分期手续费 | 0.6%-1.5%/月 | 等额本息 |
| M3+ 不良率 | **1.5%-2%** | 行业估算 |

### 3.3.3 花呗资金 ABS 链路

```text
   花呗 ABS 资产证券化
┌──────────────────────────────────────────┐
│ 1. 资产打包: 蚂蚁消金将花呗债权打包       │
│ 2. 增信: 优先/次级分层 (次级 ≥ 5%)       │
│ 3. 评级: 联合资信 AAA 评级               │
│ 4. 发行: 上交所/银行间市场                │
│ 5. 资金回流: 用于新增放款                 │
└──────────────────────────────────────────┘
```

### 3.3.4 花呗风控决策（< 100ms）

```python
# 花呗授信决策 (伪代码)
class HuabeiDecision:
    def decide(self, user_id, amount):
        # 1. 芝麻信用查询
        zhima_score = zhima_client.get_score(user_id)  # 350-950

        # 2. 行为特征 (脱敏)
        features = self.extract(user_id)

        # 3. 风险模型 (XGBoost)
        risk_score = self.risk_model.predict(features)

        # 4. 额度模型
        quota = self.quota_model.predict(features)

        # 5. 利率定价
        rate = self.pricing_model.predict(features, risk_score)

        # 6. 决策
        if risk_score > 0.7:
            return Decision.REJECT
        elif amount <= quota:
            return Decision.PASS
        else:
            return Decision.PARTIAL_PASS
```

## 3.4 借呗（现金贷 / 蚂蚁小贷）

### 3.4.1 产品差异

| 维度 | 花呗 | 借呗 |
|---|---|---|
| 场景 | 消费支付 | 现金提现 |
| 资金到账 | 商户收款 | 用户银行卡 |
| 日利率 | 0.04%-0.05% | 0.03%-0.05% |

| 监管 | 消费金融 | 网络小贷 |

## 3.5 芝麻信用（信用评分基础设施）

```text
│  ③ 履约能力 (20%)  收入资产        │

```

### 3.5.2 数据来源

## 3.6 相互宝（网络互助，已关停）

### 3.6.1 产品模式

**相互宝 = 一人生病，众人分摊的网络互助计划**（**2022 年 1 月关停**）。

```text
  相互宝模式
┌────────────────────────────────────────┐
│  用户加入 → 每月公示 → 患病申请        │
│      ↓              ↓              ↓  │
│  扣分摊金 ← 自动扣款 ← 审核通过      │
│                                        │
│  模式: 大病互助/慢病互助/老年互助       │
│  收费: 8% 管理费 (救助金 92%)         │
└────────────────────────────────────────┘
```

### 3.6.2 关停原因

- 监管定性为"类保险"，无牌照经营
- 分摊金额持续上涨（每年 200+ 元）
- 投诉率上升
- **2022 年 1 月 28 日正式关停**，用户转至商业保险

> 启示：**网络互助有"增长奇迹"，但合规性决定其生命线**。

### 3.7.4 蚂蚁链溯源示例

```solidity
// 商品溯源合约 (Solidity-like)
contract ProductTrace {
    struct Product {
        string batchId;
        string origin;
        uint256 timestamp;
        address operator;
    }

    mapping(string => Product) public products;

    function register(
        string memory batchId,
        string memory origin
    ) public {
        products[batchId] = Product(batchId, origin, block.timestamp, msg.sender);
        emit Registered(batchId, origin);
    }

    function transfer(string memory batchId, address to) public {
        products[batchId].operator = to;
        emit Transferred(batchId, to);
    }
}
```
