## A 列:组件结构设计(结构 / 字段 / 字节)

### A1 组件拆分 → 深度展开

#### 四级执行步骤
1. **业务边界识别** → 页面级 / 容器级 / 展示级 拆分
2. **复用层级抽象** → Atom / Molecule / Organism / Template / Page(原子化设计)
3. **设计系统引入** → Ant Design / Material UI / Tailwind UI
4. **跨端组件复用** → Web Components / React Native / Taro

#### 五级原子操作
- 决策矩阵:`组件复用率 × 业务复杂度 × 维护成本`
- Storybook 隔离开发:`*.stories.tsx` + Chromatic 视觉回归
- 跨端决策:Web only / RN / 小程序 / 桌面 Electron
- 拆分 Checklist:单一职责 / props < 8 / < 300 行

#### 六级参数项

| 参数 | 取值 | 业务影响 |
|------|------|---------|
| `组件粒度` | 粗(页面级) | 复用差,但组合快 |
| `组件粒度` | 中(容器+展示) | 推荐,DDD 风格 |
| `组件粒度` | 细(原子化) | 复用强,但抽象成本 |
| `复用层级` | 1 | 一次性,直接 inline |
| `复用层级` | 2-3 | 推荐(2 层抽象) |
| `复用层级` | > 3 | 过度设计,需合并 |
| `单文件行数` | < 100 | 最佳,纯展示 |
| `单文件行数` | 100-300 | 可接受,含逻辑 |
| `单文件行数` | > 300 | 需拆分 |
| `props 数量` | < 5 | 最佳 |
| `props 数量` | 5-8 | 可接受 |
| `props 数量` | > 8 | 用 Context / state 替代 |

#### 七级颗粒
- **单组件文件**:`src/components/UserCard/UserCard.tsx` — 一组件一文件夹(`.tsx` + `.module.css` + `.stories.tsx` + `.test.tsx`)
- **单 props 字段**:`interface UserCardProps { user: User; onClick?: () => void }` — TS interface 强类型
- **单字符长度**:`maxLength={32}` — antd Form.Item `maxLength` 限制
- **单格式规范**:`moment(user.createdAt).format('YYYY-MM-DD HH:mm:ss')` — dayjs/moment 时间格式化

### A2 状态管理 → 深度展开

#### 四级执行步骤
1. **状态分类** → 服务端状态 / 全局状态 / 本地状态 / URL 状态
2. **方案选型** → TanStack Query(服务端) + Zustand(全局) + useState(本地) + nuqs(URL)
3. **数据流设计** → 单向数据流 + Server State 分离
4. **持久化策略** → localStorage(用户偏好) + sessionStorage(临时) + IndexedDB(大量)

#### 五级原子操作
- 服务端状态:**TanStack Query**(SWR 同级)替代手写 useEffect + axios
- 全局状态:**Zustand 4**(轻量)或 **Redux Toolkit**(团队熟悉)
- 本地状态:**useState / useReducer**
- 表单状态:**React Hook Form**(非受控)+ Zod schema

#### 六级参数项

| 状态类型 | 推荐方案 | 替代方案 | 持久化 |
|---------|---------|---------|--------|
| **服务端状态** | TanStack Query v5 | SWR / Apollo | N/A |
| **全局 UI 状态** | Zustand 4 | Redux Toolkit / Jotai | zustand/middleware persist |
| **表单状态** | React Hook Form 7 | Formik / Final Form | (无) |
| **URL 状态** | nuqs / useSearchParams | 手写 query string | URL |
| **本地状态** | useState / useReducer | Jotai atom | (无) |
| **大量本地** | IndexedDB(Dexie) | localStorage | IndexedDB |
| **用户偏好** | localStorage | cookies | localStorage |

#### 七级颗粒
- **单 useState 调用**:`const [count, setCount] = useState(0)` — 计数器
- **单 Zustand store**:`const useStore = create<State>((set) => ({ count: 0, inc: () => set((s) => ({ count: s.count + 1 })) }))`
- **单 TanStack Query 键**:`['user', userId]` — Query Key 标准化
- **单 Zod schema**:`z.object({ email: z.string().email(), age: z.number().min(0) })`

```typescript
// frontend/web/src/store/auth.ts
// Zustand 4 + persist middleware(全局 UI 状态 + 持久化)
import { create } from 'zustand';
import { persist, createJSONStorage } from 'zustand/middleware';

interface AuthState {
  token: string | null;
  user: User | null;
  setAuth: (token: string, user: User) => void;
  clearAuth: () => void;
}

export const useAuthStore = create<AuthState>()(
  persist(
    (set) => ({
      token: null,
      user: null,
      setAuth: (token, user) => set({ token, user }),
      clearAuth: () => set({ token: null, user: null }),
    }),
    {
      name: 'openlive-auth', // localStorage key
      storage: createJSONStorage(() => localStorage),
      partialize: (state) => ({ token: state.token, user: state.user }), // 仅持久化这两个字段
    }
  )
);

// frontend/web/src/hooks/useProducts.ts
// TanStack Query v5(服务端状态,自动缓存 + 失效)
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

export const useProducts = (categoryId: string) => {
  return useQuery({
    queryKey: ['products', categoryId],     // 七级颗粒:单 Query Key
    queryFn: () => api.get(`/api/v1/products?category=${categoryId}`),
    staleTime: 5 * 60 * 1000,               // 5 分钟缓存
    gcTime: 10 * 60 * 1000,                 // 10 分钟 GC
  });
};

export const useCreateOrder = () => {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: api.post('/api/v1/orders'),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['orders'] });
    },
  });
};
```

```typescript
// XState 5 直播房间状态机
import { createMachine, assign } from 'xstate';

interface LiveRoomContext {
  viewerCount: number;
  duration: number;
  streamUrl: string | null;
  errorMessage: string | null;
}

type LiveRoomEvent =
  | { type: 'START'; streamUrl: string }
  | { type: 'JOIN' }
  | { type: 'LEAVE' }
  | { type: 'TICK'; duration: number }
  | { type: 'ERROR'; message: string }
  | { type: 'END' };

export const liveRoomMachine = createMachine({
  id: 'liveRoom',
  initial: 'idle',
  context: {
    viewerCount: 0,
    duration: 0,
    streamUrl: null,
    errorMessage: null,
  } as LiveRoomContext,
  states: {
    idle: {
      on: {
        START: { target: 'starting', actions: assign({ streamUrl: ({ event }) => event.streamUrl }) },
      },
    },
    starting: {
      invoke: {
        src: 'connectStream',
        onDone: { target: 'live' },
        onError: { target: 'error', actions: assign({ errorMessage: ({ event }) => event.data }) },
      },
    },
    live: {
      on: {
        JOIN: { actions: assign({ viewerCount: ({ context }) => context.viewerCount + 1 }) },
        LEAVE: { actions: assign({ viewerCount: ({ context }) => Math.max(0, context.viewerCount - 1) }) },
        TICK: { actions: assign({ duration: ({ event }) => event.duration }) },
        END: 'ended',
      },
    },
    ended: { type: 'final' },
    error: {
      on: { START: 'starting' },
    },
  },
});

// 在组件中使用(@xstate/react)
import { useMachine } from '@xstate/react';
export const LiveRoom: FC = () => {
  const [state, send] = useMachine(liveRoomMachine);
```

```typescript
// frontend/web/src/pages/Login/LoginForm.tsx
// React Hook Form 7 + Zod + antd
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';
import { Input, Button, Form, message } from 'antd';

// 七级颗粒:单 Zod schema
const loginSchema = z.object({
  email: z.string().email('邮箱格式错误').max(255),
  password: z.string()
    .min(8, '密码至少 8 位')
    .regex(/[A-Z]/, '需包含大写字母')
    .regex(/[0-9]/, '需包含数字'),
  remember: z.boolean().default(false),
});

type LoginForm = z.infer<typeof loginSchema>;

export const LoginForm: FC = () => {
  const { register, handleSubmit, formState: { errors, isSubmitting } } = useForm<LoginForm>({
    resolver: zodResolver(loginSchema),
    defaultValues: { remember: false },
  });

  const onSubmit = async (data: LoginForm) => {
    try {
      const res = await api.post('/api/v1/auth/login', data);
      useAuthStore.getState().setAuth(res.token, res.user);
      message.success('登录成功');
    } catch (err) {
      message.error((err as Error).message);
    }
  };

  return (
    <Form onFinish={handleSubmit(onSubmit)} layout="vertical">
      <Form.Item label="邮箱" validateStatus={errors.email ? 'error' : ''} help={errors.email?.message}>
        <Input {...register('email')} placeholder="user@example.com" maxLength={255} />
      </Form.Item>
      <Form.Item label="密码" validateStatus={errors.password ? 'error' : ''} help={errors.password?.message}>
        <Input.Password {...register('password')} placeholder="••••••" />
      </Form.Item>
      <Form.Item>
        <Button type="primary" htmlType="submit" loading={isSubmitting} block>
          登录
        </Button>
      </Form.Item>
    </Form>
  );
};
```

```typescript
// 图片懒加载
import { useEffect, useRef, useState, ImgHTMLAttributes } from 'react';

interface LazyImageProps extends ImgHTMLAttributes<HTMLImageElement> {
  src: string;
  placeholder?: string;
  rootMargin?: string;
}

export const LazyImage: FC<LazyImageProps> = ({ src, placeholder, rootMargin = '200px', ...rest }) => {
  const [loaded, setLoaded] = useState(false);
  const imgRef = useRef<HTMLImageElement>(null);

  useEffect(() => {
    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          setLoaded(true);
          observer.disconnect();
        }
      },
      { rootMargin }
    );
    if (imgRef.current) observer.observe(imgRef.current);
    return () => observer.disconnect();
  }, [rootMargin]);

  return <img ref={imgRef} src={loaded ? src : placeholder} loading="lazy" decoding="async" {...rest} />;
};
```

```nginx
    add_header Cache-Control "public, immutable";
  }
  
  # SPA fallback
  location / {
    try_files $uri $uri/ /index.html;
  }
  
  # Brotli / gzip 压缩
  brotli on;
  brotli_comp_level 6;
  gzip on;
  gzip_types text/plain text/css application/javascript application/json image/svg+xml;
}
```

### G3 灰度发布 → 深度展开

#### 四级执行步骤
1. **灰度比例** → 1% → 10% → 50% → 100%
2. **流量切换** → CDN 权重 / Nginx upstream / Feature Flag
3. **蓝绿部署** → 旧版 100% → 新版 0% → 新版 100% → 旧版下线
4. **Feature Flag** → LaunchDarkly / 自研 / Unleash

#### 五级原子操作
- **CDN 权重**:`A 版本权重 10, B 版本权重 90`
- **Nginx 切流**:`upstream backend { server v1 weight=9; server v2 weight=1; }`
- **Feature Flag**:`if (flags.isEnabled('new-checkout')) { ... }`
- **蓝绿回滚**:`切回旧版本 < 1s`

#### 六级参数项

| 灰度阶段 | 流量比例 | 监控时长 | 回滚条件 |
|---------|---------|---------|---------|
| 内部测试 | 0%(仅员工) | 1 天 | P0 错误 |
| 1% 灰度 | 1% | 4 小时 | 错误率 > 0.5% |
| 10% 灰度 | 10% | 4 小时 | 错误率 > 0.3% |
| 50% 灰度 | 50% | 2 小时 | 错误率 > 0.2% |
| 100% 全量 | 100% | 持续 | 持续监控 |

#### 七级颗粒
- **单 CDN 权重**:`A: 90, B: 10`(灰度 10%)
- **单 Feature Flag**:`flags.isEnabled('new-checkout')`
- **单监控指标**:`新版本错误率 / 旧版本错误率`
- **单回滚命令**:`nginx -s reload`(切回旧 upstream)

```typescript
import { useQuery } from '@tanstack/react-query';

interface FeatureFlags {
  newCheckout: boolean;        // 新版结算页

  darkMode: boolean;           // 暗色模式

const DEFAULT_FLAGS: FeatureFlags = {
  newCheckout: false,
  aiAssistant: false,
  multiLangLive: false,
  darkMode: true,
};

export const useFeatureFlags = (userId: string) => {
  return useQuery({
    queryKey: ['feature-flags', userId],
    queryFn: async (): Promise<FeatureFlags> => {
      // 从后端拉取(基于 userId 的灰度)
      const res = await api.get(`/api/v1/feature-flags/${userId}`);
      return { ...DEFAULT_FLAGS, ...res.data };
    },
    staleTime: 5 * 60 * 1000,
  });
};

// 使用(七级颗粒:单 Feature Flag)
export const CheckoutButton: FC = () => {
```
