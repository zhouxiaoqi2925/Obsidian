# 每日知识抓取任务框架

> 目标：每天自动抓取 10 篇开发技术知识，整理入库到 `G:\Obsidian Vault\`。
> **当前状态**：等待用户提供「抓取模板」。

│  Step 1：抓取（10 篇候选）                          │

## 二、目标目录

每天抓取内容按日期归档到：

```
G:\Obsidian Vault\Knowledge\Daily\
├── 2026-06-01\
│   ├── 01-Java-JVM-内存模型.md
│   ├── 02-MySQL-索引原理.md
│   ├── 03-Linux-Nginx-反向代理.md
│   └── ...（共 10 篇）
├── 2026-06-02\
└── ...
```

每周日合并到主目录：
- `Knowledge/01_编程语言/Java/` ← 来自 Daily 的 Java 笔记
- `Knowledge/02_数据库/MySQL/` ← 来自 Daily 的 MySQL 笔记

## 四、自动化配置（等模板到位后落地）

### 4.1 定时任务（cron）

> 使用 `mcp__scheduled-tasks__create_scheduled_task`

```yaml
taskId: daily-knowledge-harvest
cronExpression: "0 9 * * *"   # 每天 09:00
prompt: |
  读取 [[AI知识库维护系统提示词]] 作为系统提示词。
  读取 [[每日知识抓取任务框架]] 的「抓取模板」部分。
  执行每日 10 篇知识抓取 + AI 整理 + 写入 Obsidian。
  最后用 Dataview 统计今日入库数量，回报执行结果。
```

### 4.2 任务追踪（Tasks 插件）

在每篇入库笔记 frontmatter 加：
```yaml
---
task_id: "harvest-2026-06-01-03"
harvest_date: 2026-06-01
source: ""
tags: [harvest, daily, java]
---
```

### 4.3 质量统计（Dataview）

```dataview
TABLE
  rows.length as "今日入库"
FROM "Knowledge/Daily/2026-06-01"
```
