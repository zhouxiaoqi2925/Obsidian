**8 比特级索引参数**

- 索引字段前缀长度(255 截断临界)
- 填充因子 90%(频繁 UPDATE 留 10% 余量)
- 索引页大小 8KB / 16KB / 32KB
- BRIN 索引范围(>1 亿行时序数据)
- GIN 索引 pending_list 阈值

| 4.2 写入 SQL | 批量/分片/upsert/returning | COPY/批量 INSERT 待补 | P1 |
| 4.3 存储过程 | PL/pgSQL 函数 | 缺 | P2 |
| 4.4 视图触发器 | 物化视图 / 触发器 | 触发器全表审计待补 | P1 |
| 4.5 SQL 优化 | 重写/分页/游标 | OFFSET 大分页禁用 | P1 |

**9 亚比特级 SQL 优化点**
- 单字符口径语义(避免函数包裹索引列)
- 单索引失效场景(类型转换/null 判断/like 前缀)
- 单 SQL 回表次数(覆盖索引 vs 回表成本)
- 单 SQL 临时表大小(work_mem 调整)
- 单 SQL 排序开销(sort_mem / 索引顺序扫描)
- 单 SQL 扫描成本(seq_page_cost / random_page_cost)
- 单执行计划节点(Nested Loop / Hash Join / Merge Join 选型)
- 单锁粒度调整(行锁 vs 页锁 vs 表锁)
- 单毫秒级耗时优化(7ms → 1ms 路径)

**待办**
- P0:慢 SQL 日志接入(slow_query_log > 200ms)
- P1:分页 keyset 替代 OFFSET(>1 万行)
- P2:写 PL/pgSQL 物化视图(每 5 分钟刷新统计)
