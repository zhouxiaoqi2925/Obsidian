## 项目策略:简化大数据栈

> AI Live Platform 桌面版**不部署完整大数据平台**。
> 采用「PostgreSQL 物化视图 + Kafka 事件流 + 轻量 TSDB」三件套,覆盖 80% 场景。

| 原大数据组件 | 项目替代方案 | 优势 |
|------------|------------|------|
| Hadoop HDFS | PG TOAST + 归档表 | 零运维 |
| Hive 数仓 | PG 物化视图(分层 ODS/DWD/DWS/ADS) | 单数据库 |
| Spark/Flink | Go 后端实时聚合 + 物化刷新 | 复用 Go 进程 |
| HBase | PG BRIN 索引 | 单库 |
| Kafka | 已有 segmentio/kafka-go | 桌面端可降级为本地队列 |
| ClickHouse | 单副本 PG + 物化 | 降复杂度 |

**核心物化视图(项目示例)**
```sql
-- DWS 日 GMV
CREATE MATERIALIZED VIEW dws.daily_gmv AS
SELECT
  date_trunc('day', paid_at) AS dt,
  anchor_id,
  COUNT(DISTINCT order_id) AS order_cnt,
  SUM(amount) AS gmv
FROM dwd.orders
WHERE status = 'paid'
GROUP BY 1, 2
WITH NO DATA;

REFRESH MATERIALIZED VIEW CONCURRENTLY dws.daily_gmv;
```

## 总结:简化大数据栈决策

✅ **采用**:`PostgreSQL 物化视图 + Kafka + TSDB`
❌ **不引入**:Hadoop / Hive / Spark / Flink / ClickHouse / HBase

**理由**:
1. 桌面版用户量级 < 10 万 DAU,单 PG 足够
2. 复用现有 Go 后端进程,减少运维成本
3. Phase 4 零依赖战略一致
4. 业务核心是直播,非数据驱动
