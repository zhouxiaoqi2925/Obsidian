## 三、QQ 音乐嵌入扩展 (单独说明)

> 用户 2026-06-24 特别要求: 软件内嵌入 QQ 音乐, 直播中自动选曲

| 维度 | 方案 |
|------|------|
| **接入方式** | Web API (无需客户端) 或 iframe 嵌入 QQ 音乐网页版 |
| **曲库** | QQ 音乐全曲库 (~10万首), 按标签/情绪分类 |
| **搜索** | 关键词 + 情绪 + BPM + 时长 |
| **播放** | 内置音频引擎 + QQ 音乐流 (版权授权范围) |
| **选曲策略** | 时段 + 情绪 + 历史 + 协同 4 维推荐 |
| **避让** | 数字人说话 → BGM 自动降至 20%, 0.5s 内恢复 |
| **版权** | 必须使用 QQ 音乐开放平台授权 API, 不直接播放未授权音源 |
| **失败兜底** | QQ 音乐 API 挂 → 降级到本地曲库 → 再降级到静音 |
| **桌面集成** | Electron 主进程控制播放, 渲染进程 UI 显示 |

### QQ 音乐关键流程

```
主播开播 → 加载本地曲库 + QQ 音乐授权 token → 同步标签
  → 时段 + 情绪 → 推荐 10 首候选 → 主播手动选 or 自动播放
  → 数字人说话 → 触发 ducking → BGM 20% → 说话结束 → BGM 100%
  → 用户关注/下单 → 触发事件音效 → 与 BGM 并行播放
  → 直播结束 → 保存播放历史 → 学习主播偏好
```
