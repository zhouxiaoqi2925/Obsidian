## 二、九级 × 七列 矩阵骨架(适用于全部 10 领域)

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 一级 (7列)  │ A 结构 │ B 逻辑 │ C 配置 │ D 用例 │ E 校验 │ F 指标 │ G 规则 │
│ 二级 (5列)  │ 模块细分 (4-5 个并列子系统)                              │
│ 三级 (4列)  │ 子系统功能 (4 个核心功能)                                 │
│ 四级 (4列)  │ 功能步骤 (4 个执行环节)                                   │
│ 五级 (4列)  │ 步骤原子 (4 个不可拆分动作)                               │
│ 六级 (4列)  │ 原子参数 (4 个关键参数)                                   │
│ 七级 (颗粒)  │ 单字段 / 单语句 / 单指令 / 单用例 / 单步骤 / 单指标 / 单规则 │
│ 八级 (比特)  │ 单字节 / 单比特 / 单时钟周期 / 单纳秒耗时                 │
│ 九级 (亚比特)│ 量子级位态 / 皮秒时序 / 飞秒校验 / 普朗克约束             │
└─────────────────────────────────────────────────────────────────────────┘
```

## 三、拆解深度约定

| 级别 | 必填深度 | 选填深度 |
|------|----------|----------|
| 1-4 级 (模块→步骤) | 必填 (骨架) | — |
| 5 级 (原子) | 选填关键步骤 (~30-50 节点/领域) | 其余仅占位 |
| 6 级 (参数) | 选填关键原子 (~10-20 节点/领域) | 其余仅占位 |
| 7 级 (颗粒) | 选填关键参数 (单字段/单语句) | 大多数不展开 |
| 8-9 级 (比特/亚比特) | 仅性能/底层场景填 | 标记为「亚比特级」理论 |

> **量级控制**: 单领域完整 9 级展开 ≈ 14 万节点, 实际填到 5 级约 200-400 节点, 文档可读且实用。
