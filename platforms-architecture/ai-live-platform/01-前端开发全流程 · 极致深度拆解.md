## 二、7 个一级模块拆解

### 一级模块 ①: 需求设计对接 (4 大子模块)
| 二级子模块 | 三级功能 | 四级步骤 | 项目现状 |
|-----------|----------|---------|----------|
| **1.1 需求评审** | PRD 解读 / 业务背景 / 边界澄清 / 风险登记 | 业务方讲解→技术提问→拆任务→评审通过 | `docs/` 暂无 PRD 模板 |
| **1.2 设计稿验收** | 视觉一致性 / 交互一致性 / 异常态 / 文案 | Figma 验收→标注导出→设计走查 | 无 Figma 对接 |

## 三、AI 直播平台 · 前端 **完善动作清单**

### P0 (本周内)
1. **新建 `frontend/web/src/theme/`** (D-5)
   - `tokens.ts`: 设计令牌 (颜色/字号/间距/圆角/阴影)
   - `dark.ts` / `light.ts`: 双主题变量
   - `provider.tsx`: 主题上下文
   - `useTheme.ts`: 切换 hook
2. **删除 `electron/services/docker-manager.js`** (Phase 4 已完成, 桌面端不依赖 Docker)
3. **重写 `electron/services/ai-service-manager.js`**
   - 当前用 mock, 需对接 PyInstaller 打包后的 `ai-service.exe`
   - 进程健康检查 + 自动重启

### P1 (本月内)
4. **新建 `frontend/web/resources/` 目录骨架**
   - `backend/`: 嵌入的 Go 后端二进制
   - `ai-service/`: 嵌入的 Python AI 服务二进制
   - `app-update.yml`: electron-updater 配置
   - ~~`docker-compose.yml`~~ (已删, 不需要)
5. **前端监控 SDK 接入**
   - FCP/LCP/CLS 采集
   - Long Task 上报
   - 自定义埋点 (直播间进出 / 商品点击 / 支付点击)
6. **前端性能预算**
   - 首屏 JS < 250KB (gzip)
   - LCP < 2.5s
   - CLS < 0.1

### P2 (下季度)
7. **组件库完善**
   - `LiveRoomDock` 组件 props 标准化
   - `ProductCard` 复用率提升
   - `ChatPanel` 性能 (虚拟滚动)
8. **CI/CD 前端流水线**
   - PR lint + 类型检查 + 单测
   - Playwright 录制关键路径
9. **设计走查与规范文档**
   - Figma 对接 + 标注导出
   - 异常态/空态/loading 设计清单
