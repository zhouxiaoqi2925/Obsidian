## 三、关键流程时序

### 充值流程
```
用户选套餐 → 网关鉴权 → 创建支付订单 → 调起支付 SDK
  → 支付成功回调 → 写充值流水 → 加账户余额 → 通知用户
```

### AI 调用计费流程
```
AI 请求 → 网关鉴权 → 配额检查 → AI 网关路由 → 调用模型
  → 计量埋点 → 预扣 (按配额预估) → 实扣 (按实际计量) → 写流水
  → 调用失败 → 退预扣 → 写负流水
```

### 对账流程
```
T+1 凌晨 0 点 → 拉微信/支付宝账单 → 拉内部流水
  → 按订单号 join → 计算差异 → 生成对账报告
  → 差异 ≤ 1 元自动赔付 → 差异 > 1 元人工工单
```

## 四、关键不变量

1. **金额不可丢**: 任何一笔流水的预扣/实扣/退费必须可追溯
2. **幂等必达**: 同一 request_id 多次调用结果完全一致
3. **计量必准**: input_tokens + output_tokens 与模型返回完全一致
4. **余额必一致**: 任何时刻 `sum(账户余额) = sum(初始充值 - 实扣 + 退款)`
5. **故障必自愈**: 支付回调 3 次失败 → 走轮询 → 仍失败走人工
