## 三、关键指标 SLO

| 指标 | 目标 | 测量方法 |
|------|------|----------|
| 端到端延迟 | ≤ 800ms (用户提问 → 数字人回复) | trace_id 全链路 |
| 口型同步误差 | ≤ 50ms | 音视频对齐分析 |
| ASR 识别率 | ≥ 95% | 测试集 |
| TTS MOS 评分 | ≥ 4.0 | 人工评测 |
| 弹幕回复率 | ≥ 80% | 实时统计 |
| 数字人渲染帧率 | ≥ 30fps | 性能监控 |
| 直播可用性 | ≥ 99.9% | 心跳检测 |
| 紧急停播 RTO | ≤ 5s | 故障演练 |
