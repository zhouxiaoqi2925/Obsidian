## 下次启动失败的常见排查点（给未来会话用）
1. 看不到 `mcp__obsidian__*` 工具 → 检查 `~/.codex/config.toml` 末尾 `[mcp_servers.obsidian]` 是否还在；
   `config.toml.bak-2026-07-06` 是 2026-07-06 22:37 版本（备份前）。
2. `obsidian-mcp-server` 启动报 `OBSIDIAN_API_KEY: undefined` → config 里 env 段被吃；检查引号。
3. `ENOTFOUND 127.0.0.1:27124` 或 `ECONNREFUSED` → Obsidian 没启动或 Local REST API 插件未启用；
   先在 Obsidian 内命令面板跑 "Local REST API: Start server" 一次。
4. HTTP 401 但连接成功 → API key 已过期，需要在 Obsidian 重新生成并同步更新 config.toml。
