## 一、分布式系统案例 (20份)

### 基础设施

1. **避免retry风暴**
   - 问题：大量客户端同时重试导致级联失败
   - 方案：指数退避 + 抖动 + 熔断
   - 关键参数：baseDelay, maxDelay, jitter
   - 代码示例：Java/Python 重试实现

2. **健康检查最佳实践**
   - 问题：如何正确判断服务健康
   - 方案：分层健康检查
   - ELB + 应用层 + 依赖服务
   - 健康阈值设置

3. **使用Read Replicas**
   - 场景：读写分离架构
   - 一致性挑战与解决方案
   - 复制延迟处理
   - 路由策略设计

4. **多区域数据复制**
   - 问题：跨区域数据同步
   - 方案：Cassandra 跨区域复制
   - 冲突解决策略
   - 延迟与一致性权衡
