## 一、核心机制

### 1. 选择器引擎 d3-selection（Selection Engine）

**问题场景**：浏览器原生 `querySelectorAll` 返回静态 NodeList，拿到节点后无法"链式"操作：选元素 → 改属性 → 加事件 → 加 transition → 加子节点，每步都得重新 query。D3 的 `d3.select()` 返回一个 Selection 对象，类似 jQuery 风格，但绑定"数据"作为隐式上下文。**核心创新：把"数据"和"DOM 节点"绑定在一起**，链式 API 携带数据自动传递。

**解决方案**：
```javascript
// d3-selection 核心伪代码
class Selection {
  constructor(groups, parents) {
    this._groups = groups;  // Array<Array<Node>>：每个 group 是一组节点
    this._parents = parents; // 父节点
  }
  select(selector) {
    // 在每个 group 上 querySelector
    const subgroups = this._groups.map(nodes =>
      nodes.map(n => n.querySelector(selector)).filter(Boolean)
    );
    return new Selection(subgroups, this._parents);
  }
  selectAll(selector) {
    // 同层兄弟节点一次性选
    const subgroups = this._groups.map(nodes => {
      const result = [];
      for (const node of nodes) {
        result.push(...node.querySelectorAll(selector));
      }
      return result;
    });
    return new Selection(subgroups, this._parents);
  }
  attr(name, value) {
    // 给每个节点设置属性，value 是函数时传 (d, i, nodes) 数据
    this._groups.forEach((group, groupIndex) => {
      group.forEach((node, nodeIndex) => {
        const v = typeof value === 'function'
          ? value(node.__data__, nodeIndex, group)
          : value;
        node.setAttribute(name, v);
      });
    });
    return this;  // 链式
  }
  data(data, key) {
    // data join 核心
    // ...
    return new Selection(...);
  }
}
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| _groups | Array<Array<Node>> | 多 group 支持 nested selection |
| __data__ | 节点属性 | 隐式数据绑定 |
| 链式 | 总是 return this | jQuery 风格 |
| 选择器 | 任意 CSS | `querySelector` 子集 |
| 性能 | 1ms / 100 节点 | 实际场景无感 |

**最佳实践**：
1. ✅ `__data__` 隐式绑定：避免显式 `Map<Node, Data>` 查询
2. ✅ 链式 API 携带数据：attr/transition/datum 都自动传数据
3. ✅ select vs selectAll：select 选第一个匹配，selectAll 选全部
4. ✅ 函数 value：`attr('cx', (d) => d.x)` 比 for 循环更声明式
5. ✅ 多 group：嵌套 selection 用 `_groups: Array<Array<Node>>`
6. ✅ 避免反复 select：链式一次做完所有操作

### 2. 数据绑定 + 键函数（Data Join + Key Function）

**问题场景**：数据更新时（动态柱状图），如何处理"enter（新增）、update（更新）、exit（删除）"三状态？传统做法是 diff 旧数据 + 新数据，手动 add/remove 节点。D3 的 data join 模式：用 `key` 函数标识数据身份，自动分出 enter/update/exit 三个子选择。**这是 d3 抽象最天才的一笔**。

**解决方案**：
```javascript
// d3-selection data() 核心算法
data(data, key) {
  // 1) 当前 selection 现有节点（带 __data__）
  const oldGroups = this._groups;
  // 2) 键函数：key(d) 返回数据身份
  const keyFn = key || ((d, i) => i);  // 默认按索引
  // 3) 建立旧节点 map
  const oldNodesByKey = new Map();
  oldGroups.forEach(group => group.forEach(node => {
    const k = keyFn(node.__data__, ...);
    oldNodesByKey.set(k, node);
  }));
  // 4) 对新数据每项，找旧节点或 null
  const newGroups = data.map(d => {
    const k = keyFn(d);
    return oldNodesByKey.get(k) || null;  // null = enter
  });
  // 5) exit 集合
  const exitGroups = oldGroups.map(group => group.filter(node => {
    const k = keyFn(node.__data__);
    return !data.some(d => keyFn(d) === k);
  }));
  // 6) 返回 update 子集（newGroups 非空节点）
  //    enter 子集（newGroups 空节点）
  //    exit 子集（旧节点不在新数据）
  return {
    update: new Selection(newGroups.map(g => g.filter(Boolean)), this._parents),
    enter:  new Selection(newGroups.map(g => g.map(() => createPlaceholder())), this._parents),
    exit:   new Selection(exitGroups, this._parents),
  };
}
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| key | 唯一标识 | 字符串、数字、对象引用 |
| 默认 key | 索引 | 不稳定，慎用 |
| enter 占位 | placeholder 节点 | 后续 .append() 转 real |
| exit 处理 | .remove() 或 .transition().remove() | 动画删除 |
| update | 默认操作 | 属性更新 |

**最佳实践**：
1. ✅ 稳定 key：对象用 id、数字用 value，**绝不用默认索引**
2. ✅ enter + update + exit 三段式：`selection.enter().append().merge(update)`
3. ✅ exit 不要立即 remove：先 transition fade out 再 remove
4. ✅ key 函数要快：O(N) 调用，要纯函数
5. ✅ 配合 transition：enter 从下进入、update 平滑插值、exit 淡出
6. ✅ 数据 immutable：新数据全替换，不要 mutate 旧

### 3. 比例尺变换 d3-scale（Scale Transforms）

**问题场景**：数据值（如 GDP 范围 0-100B）要映射到像素位置（0-1000px）。如果直接线性 `x = data * 10`，数据小、屏幕小、刻度不均。d3-scale 提供 12 种 scale：linear / log / pow / time / sequential / diverging / quantize / quantile / threshold / ordinal / band / point。**每种 scale 解决一类映射问题**。

**解决方案**：
```javascript
// d3-scale 抽象
function scaleLinear(domain, range) {
  // domain = [0, 100B], range = [0, 1000px]
  const [d0, d1] = domain;
  const [r0, r1] = range;
  const k = (r1 - r0) / (d1 - d0);  // 斜率
  const b = r0 - k * d0;             // 截距
  function scale(value) {
    return k * value + b;            // 线性插值
  }
  scale.domain = function(_) { return arguments.length ? (domain = _, scale) : domain; };
  scale.range = function(_) { return arguments.length ? (range = _, scale) : range; };
  scale.ticks = (n = 10) => computeTicks(domain, n);  // 刻度
  scale.tickFormat = (n, specifier) => ...;
  return scale;
}

// 用法
const xScale = d3.scaleLinear()
  .domain([0, d3.max(data, d => d.gdp)])
  .range([0, 1000]);
svg.selectAll('rect')
   .attr('width', d => xScale(d.gdp));
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| domain | 数据值范围 | 输入 |
| range | 像素范围 | 输出 |
| 12 种 scale | linear/log/pow/time/... | 不同映射 |
| ticks(n) | 默认 10 | 计算刻度 |
| invert | 像素 → 数据 | 反向 |
| clamp | true | 限制在 range |

**最佳实践**：
1. ✅ 选择合适的 scale：log 用于指数数据、time 用于日期、band 用于柱状图
2. ✅ domain 自适应：`d3.extent(data, d => d.value)` 自动算范围
3. ✅ nice()：让 domain 边界对齐到整数（如 0、1、1.5）
4. ✅ 配合 axis：d3.axisBottom(xScale) 自动生成坐标轴
5. ✅ 用 invert：鼠标事件反查数据值
6. ✅ 缓存 scale：同一 dataset 不要重复算 domain

### 4. 形状生成器 d3-shape（Shape Generator）

**问题场景**：折线图、面积图、饼图、弦图等几何形状，手写 SVG path 字符串 d="M0,0 L100,100" 容易出错。d3-shape 把"数据 → path 字符串"封装成 lineGenerator、areaGenerator、arcGenerator 等。**d 属性的"d3 表达式"是声明式绘图的基础**。

**解决方案**：
```javascript
// d3-shape line generator
const line = d3.line()
  .x(d => xScale(d.date))
  .y(d => yScale(d.value))
  .curve(d3.curveMonotoneX);  // 平滑曲线

svg.append('path')
  .datum(data)
  .attr('d', line)
  .attr('fill', 'none')
  .attr('stroke', 'steelblue');

// arc generator (饼图)
const arc = d3.arc()
  .innerRadius(50)
  .outerRadius(100)
  .padAngle(0.02);

const pie = d3.pie()
  .value(d => d.value)
  .sort(null);

svg.selectAll('path')
  .data(pie(data))
  .enter().append('path')
  .attr('d', arc)
  .attr('fill', (d, i) => color(i));

// 12+ 种 curve
// curveLinear、curveMonotoneX、curveBasis、curveCardinal、curveCatmullRom...
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| x/y accessor | 函数 | 从数据提取坐标 |
| curve | curveMonotoneX | 平滑且无超调 |
| innerRadius/outerRadius | 数字 | arc 专用 |
| padAngle | 0.02 | arc 间间隙 |
| cornerRadius | 4 | arc 圆角 |

**最佳实践**：
1. ✅ 选合适的 curve：折线用 monotoneX（不震荡）、面积用 basis（平滑）
2. ✅ datum vs data：单个 path 用 datum，多个 path 用 data
3. ✅ 配合 transition：line.datum() 重设 + transition attr('d')
4. ✅ arc + pie 解耦：pie 算角度，arc 算几何
5. ✅ 用 stack：堆叠图用 d3.stack() 自动算 baseline
6. ✅ symbol generator：散点图形状（圆/方/三角）自动生成

### 5. 力导向布局 d3-force（Force Layout）

**问题场景**：社交网络图 1000+ 节点 + 5000+ 边，节点位置 x/y 怎么算？手写物理模拟（电荷斥力 + 弹簧 + 中心引力）代码量大。D3 的 d3-force 提供了 6 种力 + Verlet 积分器，**simulate() 一次函数搞定**。

**解决方案**：
```javascript
// d3-force 核心
const simulation = d3.forceSimulation(nodes)
  .force('charge', d3.forceManyBody().strength(-300))      // 电荷斥力
  .force('link',   d3.forceLink(edges).id(d => d.id).distance(50))  // 弹簧
  .force('center', d3.forceCenter(width / 2, height / 2))  // 中心
  .force('collide', d3.forceCollide().radius(20))           // 碰撞
  .force('x', d3.forceX(width / 2).strength(0.05))         // x 偏置
  .force('y', d3.forceY(height / 2).strength(0.05))        // y 偏置

simulation.on('tick', () => {
  // 每帧更新节点位置
  link.attr('x1', d => d.source.x).attr('y1', d => d.source.y)
      .attr('x2', d => d.target.x).attr('y2', d => d.target.y);
  node.attr('cx', d => d.x).attr('cy', d => d.y);
});

// 6 种力：
// forceManyBody：电荷（斥力/引力）
// forceLink：弹簧（边）
// forceCenter：中心引力
// forceCollide：碰撞检测
// forceX/forceY：坐标偏置
// 用户可自定义 force

// Verlet 积分（velocityVerlet 算法）
// x_new = x + (x - x_prev) * alpha + a * dt^2
// 数值稳定 + 阻尼
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| alpha | 1.0 初始 → 0.001 终止 | 温度 |
| alphaMin | 0.001 | 停止阈值 |
| alphaDecay | 0.0228 | 冷却速度 |
| velocityDecay | 0.4 | 阻尼 |
| 迭代次数 | 300 默认 | 通常足够 |

**最佳实践**：
1. ✅ 固定某些节点：`node.fx = x; node.fy = y` 拖动时固定
2. ✅ 性能调优：节点数 > 1000 考虑用 quadtree
3. ✅ alpha 重置：`simulation.alpha(0.5).restart()` 拖动时重启
4. ✅ 配合 zoom：让图能缩放平移
5. ✅ tick 节流：不要每帧更新 DOM，用 requestAnimationFrame
6. ✅ 自定义力：实现 `(alpha) => { for (i...) node.vx += ... }`

### 7. ESM Re-export 门面（ESM Re-export Façade）

**问题场景**：用户只想 `import * as d3 from "d3"` 拿到所有 API，不想手动 import 30 个子包。但如果元仓手动维护 `export { x } from 'd3-x'`，每加一个 API 要改元仓。d3 元仓 `src/index.js` 30 行搞定：每行 `export * from "d3-*"`。**元仓纯门面，零业务代码**。

**解决方案**：
```javascript
// src/index.js — 30 行 re-export
export * from "d3-array";
export * from "d3-color";
export * from "d3-format";
export * from "d3-interpolate";
export * from "d3-time";

export * from "d3-shape";
```

**关键参数**：

| 参数 | 推荐值 | 说明 |

| 文件行数 | 30+ | 极薄 |
| re-export 方式 | `export *` | 通配 |

**最佳实践**：
1. ✅ 元仓不要加业务代码：纯门面
2. ✅ 用 `export *` 不用手列：避免维护
3. ✅ 加新包 = package.json + 一行：门槛极低
4. ✅ Tree-shaking 友好：用户按需 import

6. ✅ 文档归元仓 docs/：子仓不维护

### 8. 配置驱动多产物打包（Config-Driven Multi-Format）

**问题场景**：库要支持 UMD（浏览器 script 标签）、ESM（现代 bundler）、min（生产环境）。手写 3 个 build 脚本维护困难。d3 用 Rollup 配置数组：基础 config + ESM config + min config 共享基础，差异只在 output 和 plugins。**单源真相，加格式只需数组加一项**。

**解决方案**：
```javascript
// rollup.config.js — 66 行
import { terser } from "rollup-plugin-terser";
import * as meta from "./package.json";

// 提取 LICENSE 中的 Copyright 行
const banner = `//! ${meta.name} v${meta.version} ...`;
const licenseLines = readFileSync("LICENSE", "utf-8")
  .split("\n")
  .filter(line => line.includes("Copyright"));

const config = {
  name: "d3",
  input: "bundle.js",
  plugins: [/* 共享插件 */],
  banner: [banner, ...licenseLines].join("\n"),
};

const min = {
  ...config,
  output: { file: "dist/d3.min.js", format: "umd", ... },
  plugins: [
    ...config.plugins,
    terser({
      mangle: { reserved: ["InternMap", "InternSet"] }
    })
  ],
};

// 配置数组：rollup 自动遍历
export default [
  { ...config, output: { file: "dist/d3.js", format: "umd" } },
  { ...config, output: { file: "dist/d3.esm.js", format: "esm" } },
  min
];
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 输出格式 | 3 种 | UMD / ESM / min |
| Rollup 版本 | 3 | ESM-first |
| Terser | 保留 InternMap/InternSet | 调试需要 |
| Banner | 自动从 LICENSE 提取 | 改 LICENSE 不用改 build |
| 单源真相 | config 数组 | 加格式数组加一项 |

**最佳实践**：
1. ✅ 配置数组：rollup 自动遍历生成
2. ✅ spread 共享基础：避免复制粘贴
3. ✅ Terser 保留关键符号：避免被压成单字母
4. ✅ Banner 自动提取：版权信息不维护
5. ✅ ESM + UMD 双格式：浏览器 + Node
6. ✅ 监控 bundle size：加包要 justify

### 9. 反射式契约测试（Reflective Contract Testing）

**问题场景**：d3 元仓只有 30 行 re-export，怎么测试"所有 30 个子包的所有 API 都能在 d3 命名空间找到"？手写 30 个 import + 断言极不优雅。d3 的解法：反射遍历 `package.json.dependencies`，自动 import 每个子包，断言每个 export 都在 d3 命名空间。**测试永不腐烂**。

**解决方案**：
```javascript
// test/d3-test.js — 20 行反射契约
import * as d3 from "../src/index.js";
import { readFileSync } from "fs";

const dependencies = Object.keys(
  JSON.parse(readFileSync("package.json", "utf-8")).dependencies
);

describe("d3 facade", () => {
  for (const dep of dependencies) {
    it(`re-exports all from ${dep}`, async () => {
      const subPackage = await import(dep);
      // 对每个子包 export，断言 d3 也有
      for (const name of Object.keys(subPackage)) {
        assert(d3[name] !== undefined,
          `d3.${name} is missing (re-export of ${dep})`);
      }
    });
  }

  it("exposes version", () => {
    assert.equal(typeof d3.version, "string");
  });
});
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 文件行数 | 20 | 极简 |
| 测试来源 | package.json.dependencies | 反射 |
| 断言数 | 30 子包 × N export | 动态 |
| 维护成本 | 0 | 加 API 自动覆盖 |
| 失败定位 | 子包名 + export 名 | 精准 |

**最佳实践**：
1. ✅ 反射优先：不写预期列表
2. ✅ 来源单一：package.json 唯一真相
3. ✅ 动态 import：覆盖 ESM 异步加载
4. ✅ 失败信息明确：哪个子包哪个 export 缺失
5. ✅ 加 API 自动覆盖：无需改测试
6. ✅ 配合 type 测试：TypeScript 自动校验 export

## 三、性能优化

### 11. 字符串驻留（String Interning）

**问题场景**：d3 在数据处理里大量用字符串键（如 scale 域名、时间格式），重复创建字符串对象浪费内存且影响 Map/Set 的 hash 性能。Mike Bostock 自研 `InternMap` / `InternSet`：**相同字符串只存一份**，比较时用引用相等而非值相等，性能提升 5-10x。

**解决方案**：
```javascript
// d3-array/src/internMap.js 核心
class InternMap extends Map {
  get(key) {
    return super.get(intern(key));
  }
  has(key) {
    return super.has(intern(key));
  }
  set(key, value) {
    return super.set(intern(key), value);
  }
}

const interned = new Map();  // 字符串 → interned string
function intern(str) {
  if (typeof str !== "string") return str;  // 非字符串原样
  if (!interned.has(str)) interned.set(str, str);
  return interned.get(str);
}

// 用户用
const map = new InternMap();
map.set("foo", 1).set("foo", 2);
// 内部只一份 "foo" 字符串
// get("foo") === get(new String("foo")) 是引用相等
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 实现 | Map 持有 | O(1) 查找 |
| 性能 | 5-10x | Map/Set 操作 |
| Terser 保留 | InternMap, InternSet | 调试需要 |
| 适用 | 字符串键 Map/Set | 大数据量 |
| 限制 | 非字符串原样 | 不通用 |

**最佳实践**：
1. ✅ 大量重复字符串：用 InternMap
2. ✅ 引用相等比值相等快：避免 hash 计算
3. ✅ 保留符号名：terser 不可压
4. ✅ 配合 Map/Set 用：API 兼容
5. ✅ 谨慎用于长生命周期：intern 永不释放
6. ✅ 测试覆盖：引用相等语义

### 12. Geo Projection 投影流水线（Geo Projection Pipeline）

**问题场景**：地球是球面（GeoJSON 是经纬度），要在 2D 屏幕画出来需要投影：墨卡托、阿尔伯斯、球面 orthographic……d3-geo 提供 30+ 种投影，每种都"流水线"——`project(λ, φ) → invert(x, y)`，可组合 + 可裁剪 + 可旋转。**核心是 d3.geoProjection() 工厂**。

**解决方案**：
```javascript
// d3-geo 核心：投影流水线
function geoProjection(project) {
  let projection = function(λ, φ) {
    // λ = longitude, φ = latitude (radians)
    const p = project(λ, φ);
    return [p[0] * k, p[1] * k];  // k = scale factor
  };
  projection.invert = function(x, y) {
    const p = project.invert(x / k, y / k);
    return p && [p[0] * radians, p[1] * radians];
  };
  projection.scale = function(_) {
    return arguments.length ? (k = _, projection) : k;
  };
  projection.translate = function(_) {
    return arguments.length ? (tx = +_[0], ty = +_[1], projection) : [tx, ty];
  };
  projection.clipExtent = function(_) { /* ... */ };
  projection.rotate = function(_) { /* ... */ };
  projection.precision = function(_) { /* ... */ };
  projection.stream = function(stream) {
    // 流水线：每个 transform 一段
    return clipExtent.stream(rotate.stream(scaleReflectY.stream(
      projection.stream(stream))));
  };
  return projection;
}

// 用法
const projection = d3.geoMercator()
  .scale(150)
  .translate([width / 2, height / 2]);
const path = d3.geoPath(projection);
svg.selectAll('path')
  .data(countries.features)
  .enter().append('path')
  .attr('d', path);
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 投影种类 | 30+ | mercator/albers/orthographic/... |
| 流水线 | clip → rotate → scale → reflect → project | 可中断 |
| 精度 | 0.1px 默认 | precision() |
| 旋转 | 任意轴 | rotate([λ, φ, γ]) |
| 裁剪 | 矩形 | clipExtent() |

**最佳实践**：
1. ✅ 选合适投影：mercator（导航）、albers（统计）、orthographic（地球）
2. ✅ 流水线可中断：stream() 注入自定义 transform
3. ✅ precision() 调优：减少剪线 artifact
4. ✅ rotate() 做动态旋转：地球动画
5. ✅ clipExtent 防溢出：球面投影出屏
6. ✅ geoPath 缓存：同一 geometry 多次画

**解决方案**：

```javascript
// d3-transition 核心
const t = d3.transition()
  .duration(750)
  .ease(d3.easeCubicInOut);

d3.selectAll('rect')
  .transition(t)
  .attr('width', d => xScale(d.value))
  .style('fill', 'steelblue');

// d3.easeCubicInOut 内部
function cubicInOut(t) {
  return ((t *= 2) <= 1 ? t * t * t : (t -= 2) * t * t + 2) / 2;
}

// d3.interpolateNumber / interpolateString / interpolateColor / interpolateArray
// 自动选择：值是数字 → interpolateNumber，字符串 → interpolateString

// 30+ ease
// easeLinear, easeQuadIn, easeQuadOut, easeQuadInOut

// easeSinIn, easeSinOut, easeSinInOut
// easeExpIn, easeExpOut, easeExpInOut
// easeCircleIn, easeCircleOut, easeCircleInOut
```

### 15. InternMap/InternSet 数据结构（InternMap/InternSet）

**问题场景**：d3-selection 数据 join、d3-hierarchy 节点索引、d3-scale 域名查找，**大量 string-key Map 操作**。原生 Map 用值相等，每次 hash 字符串 100-500ns。d3-array 自研 `InternMap` / `InternSet`：**字符串先去重表，引用相等比较**，性能提升 5-10x。

**解决方案**：
```javascript
// d3-array/src/internMap.js
class InternMap extends Map {
  constructor(entries, key = intern) {
    super();
    this._intern = key;
    this._key = key;
    if (entries) for (const [k, v] of entries) this.set(k, v);
  }
  get(key) { return super.get(this._intern(key)); }
  has(key) { return super.has(this._intern(key)); }
  set(key, value) {
    super.set(this._intern(key), value);
    return this;
  }
  delete(key) { return super.delete(this._intern(key)); }
}

function intern(value) {
  return value !== null && typeof value === "object"
    ? value
    : stringIntern.get(value) || stringIntern.set(value, value), value;
}
const stringIntern = new Map();

// 用法
const data = new InternMap();
data.set("New York", 8000000);
data.set("Tokyo", 14000000);
data.set("New York", 8100000);  // 覆盖
// 内部只一份 "New York" 字符串
```

**关键参数**：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 实现 | Map 持有 intern 表 | O(1) 查找 |
| 性能 | 5-10x | 字符串 key 场景 |
| API | 兼容 Map/Set | 直接替换 |
| 适用 | 大量重复字符串 | 真实数据 |
| 内存 | 只多一份 | 1 字符串 → 1 引用 |

**最佳实践**：
1. ✅ 大量重复字符串：用 InternMap 替代 Map
2. ✅ 数据 join 必用：selection.data() 内部用
3. ✅ 配合 TypeScript：d.ts 定义 .has/.get
4. ✅ 测试引用相等：单测覆盖
5. ✅ 监控内存：intern 永不释放
6. ✅ 配合 d3-collection：旧 API 兼容
