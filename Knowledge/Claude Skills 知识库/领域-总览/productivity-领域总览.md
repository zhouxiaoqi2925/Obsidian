# Productivity 领域总览

## 1. 领域定位

**Productivity 领域**提供 **6 个**生产力 Skill，覆盖时间管理、会议分析、回顾会、记忆、知识等。

## 2. Skills

- **remember** — 记住（持久记忆）
- **reflect** — 反思
- **meeting-analyzer** — 会议分析
- **retro** — 回顾会
- **inbox-setup** — 收件箱设置
- **inbox-triage** — 收件箱分诊
- **resume** — 简历
- **internal-comms** — 内部沟通
- **roast** — Roast（讽刺式反馈）

## 3. 工作流示例

### 3.1 会议分析
```
用户：分析这个会议记录

Claude（自动调用 meeting-analyzer）：
1. 提取决议项
2. 提取行动项（谁/做什么/何时）
3. 识别未解决问题
4. 输出结构化总结
```

### 3.2 回顾会
```
用户：开 Sprint 回顾会

Claude（自动调用 retro）：
1. 收集 went well / went poorly / actions
2. 识别模式
3. 生成下次改进项
```
