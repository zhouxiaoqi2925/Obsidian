## 3. 关键框架

### 3.1 RICE 优先级
```
RICE = (Reach × Impact × Confidence) / Effort
- Reach: 影响多少用户
- Impact: 影响程度（0.25/0.5/1/2/3）
- Confidence: 信心度（%）
- Effort: 人/月
```

### 3.2 OKR
- Objective（目标）：定性、有挑战
- Key Results（关键结果）：可测量、3-5 个

### 3.3 用户故事
```
作为 <角色>
我想要 <功能>
以便 <价值>

验收标准：
- Given ...
- When ...
- Then ...
```
