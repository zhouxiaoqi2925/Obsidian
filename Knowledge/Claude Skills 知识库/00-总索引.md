# Claude Skills 知识库 - 总索引

## 0. 知识库定位

本知识库收录了 6 个 GitHub 顶级开源仓库中的 **Claude Skills**，共 **1000+ 个**生产就绪的 Skill。每个 Skill 都被详细解析：
- 它是干什么的（一句话定位 + 解决问题）
- 工作流（步骤拆解）
- 源码解析（Python 工具、参考文档、资产模板）
- 调用示例（真实使用场景）
- 与其它 Skill 的关系

**目的**：让你**不用记名字、不用查文档**，Claude 在对话中会根据你的需求**自动调用最合适的 Skill**。

## 5. 怎么用这个知识库

### 方式 1：被动使用（推荐）
**你直接告诉 Claude 你要做什么，Claude 自动挑 Skill**：
- "帮我设计数据库" → Claude 用 `database-designer`
- "审查我的代码" → Claude 用 `code-review` + `api-design-reviewer`
- "我要做混沌工程" → Claude 用 `chaos-engineering`

### 方式 2：主动查询
**你想知道某个 Skill 怎么用**：
- 在 Obsidian 中搜索 Skill 名字
- 看对应笔记的"调用示例"章节

### 方式 3：组合使用
**复杂任务需要多个 Skill 协作**：
- 完整开发流程：spec-driven-workflow → codebase-onboarding → database-designer → api-design-reviewer → code-review → ship-gate
