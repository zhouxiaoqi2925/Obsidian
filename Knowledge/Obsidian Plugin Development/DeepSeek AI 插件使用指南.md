# DeepSeek AI 插件使用指南

**适用版本**：V3.0
**创建时间**：2026-05-31

---

## 一、插件入口

在 Obsidian 左侧边栏或命令面板中查找：
- **DeepSeek AI**（普通对话）
- **Dev: xxx**（10 个开发工具）
- **AgentPipeline**（智能体流水线）

---

## 二、功能详解

### 2.1 普通对话模式
- 输入问题，AI 即时回答
- 支持联网搜索（开启后自动全网搜集资料）
- 支持专家思考模式（深度推理）
- 可同时开启联网+专家模式

### 2.2 开发工具集（Dev 命令）

| 命令 | 快捷入口 | 用途 |
|------|----------|------|
| Dev: 代码审查 | 命令面板输入 | 分析代码质量、安全、性能 |
| Dev: 技术方案设计 | 命令面板输入 | 生成架构设计方案 |
| Dev: Bug诊断 | 命令面板输入 | 诊断并修复 Bug |
| Dev: Schema生成 | 命令面板输入 | 生成数据库 Schema |
| Dev: 需求拆分 | 命令面板输入 | 将需求拆分为用户故事 |
| Dev: 代码解说 | 命令面板输入 | 解释代码逻辑 |
| Dev: 测试生成 | 命令面板输入 | 生成测试用例 |
| Dev: 提交信息 | 命令面板输入 | 生成规范的 Git 提交信息 |
| Dev: 配置生成 | 命令面板输入 | 生成配置文件 |
| Dev: 智能体流水线 | 命令面板输入 | 5阶段自动执行项目分析 |

### 2.3 智能体流水线
**使用步骤**：
1. 点击 `Dev: AgentPipeline` 或命令面板输入
2. 输入项目目标或需求描述
3. AI 自动规划 5 阶段
4. 逐阶段执行分析
5. 最终生成架构图 + 思维导图

**适用场景**：
- 新项目启动规划
- 复杂需求分析
- 技术方案评审

## 四、使用技巧

### 4.1 获取最佳回答
1. **明确问题**：提供具体的上下文
2. **开启联网**：需要最新信息时开启
3. **开启专家**：复杂问题时开启专家模式
4. **分步执行**：先用需求拆分，再用其他工具

### 4.2 智能体流水线使用
```
✅ 好的输入示例：
"帮我分析这个 React 项目的架构，给出优化建议"

❌ 不好的输入：
"分析一下"
```

### 4.3 开发工具组合使用
```
需求来了 →
  1. 需求拆分（理解需求）
  2. 技术方案设计（规划架构）
  3. Schema生成（设计数据库）
  4. 测试生成（编写测试）
  5. 代码审查（最终检查）
```

## 五、常见问题

### 5.1 插件不显示
**解决**：
1. 检查 data.json 配置是否正确
2. 重启 Obsidian
3. 检查社区插件是否启用

### 5.2 API 调用失败
**解决**：
1. 检查 API Key 是否有效
2. 检查网络连接
3. 查看控制台错误信息

### 5.3 回答质量不佳
**解决**：
1. 开启专家思考模式
2. 提供更多上下文
3. 开启联网搜索获取最新信息
