# SRS 闪记卡 - DevOps

## CI/CD

CI 指的是::持续集成 (Continuous Integration)

CD 指的是::持续交付 (Continuous Delivery) 或 持续部署 (Continuous Deployment)

Jenkins 的核心功能是::CI/CD 编排任务调度

## 容器化

Docker 的核心概念是::容器（轻量级虚拟化），镜像、容器、仓库

Kubernetes 简称为::K8s

K8s 的核心组件包括::Pod、Service、Deployment、StatefulSet、ConfigMap、Secret

Pod 是 K8s 中::最小的可部署单元

## 监控

Prometheus 是::时序数据库 + 监控告警系统

Grafana 的作用是::可视化监控数据

ELK 中 E/L/K 分别指::Elasticsearch、Logstash、Kibana

## Git

Git 的三大工作区是::工作区、暂存区、版本库

Git rebase 和 merge 的区别是::rebase 改写历史（线性），merge 保留分支
