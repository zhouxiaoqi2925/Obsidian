## 📊 核心概念速查

### SOLID 速记

```
S - 单一职责：一个类做一件事
O - 开闭原则：扩展而不修改
L - 里氏替换：子类替换父类
I - 接口隔离：小而专的接口
D - 依赖反转：依赖抽象而非具体
```

### 架构选型

```
复杂度低 → 单体架构
复杂度中 → 分层架构
复杂度高 → 微服务 / 事件驱动
```

### 分层架构4层

```
表现层 → 业务层 → 应用层 → 数据层
(UI)    (逻辑)   (编排)   (存储)
```

### 微服务基础设施

```
服务发现 | API Gateway | 容器编排 | 消息队列 | 监控 | 日志 | 配置中心
```
